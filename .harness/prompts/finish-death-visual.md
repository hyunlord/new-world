## Buffer Schema (verification contract — pins A1/A2 cross-type equality)
The `recent_deaths` buffer is a growable list; each entry carries four fields whose
types the assertions below assume so that every `==` is unambiguous about whether a
cast is involved:
- `x`: integer tile coordinate (`i32`) — same type as the agent `Position` tile field.
- `y`: integer tile coordinate (`i32`).
- `reason`: a `DeathReason` enum value (NOT a pre-cast integer — the u8/i32 cast happens only at the FFI boundary).
- `tick`: unsigned simulation tick (`u32`).
Consequence: A1 compares natively (`i32==i32`, `DeathReason==DeathReason`, `u32==u32`) — no cast in the buffer-layer assertion. The widening casts (`x as i32`, `reason.as_u8() as i32`, `tick as i64`) live ONLY in the FFI layer and are A2's subject. If a Generator stores spatial fields as `f64`, the `x == position.tile_x` check would silently truncate at the cast — pinning `i32` here forbids that ambiguity.

## Edge Cases
- Death on tile (0,0): `x`/`y` of 0 must be a real recorded entry, not confused with a "no data" sentinel — buffer entries are always genuine (no `-1` sentinel for deaths, unlike SeekTarget). Owned by A12 (xs[0]==0, ys[0]==0, ticks[0]==0 → 1 row, not dropped).
- Death at tick 0: the `tick` field == 0 is a genuine value; `age = current_tick.saturating_sub(entry.tick)` must not underflow or treat 0 as empty. Owned by A12's `(0,0)`/`tick==0` fixture.
- `tick > current_tick` saturating_sub underflow: a future-tick entry must clamp age to 0 with no panic. Now an OWNED check in A12 (sub-check 2: inject such an entry, assert no panic + age == 0), not conditional prose.
