- **K2.2 `val_eff` cases.** The 24 cells involve only the W3 arms (`sp240L`, `gf240E`, `rw120E`), so `val_eff` rolls the val replicate-0 cases of those arms only (233 of the 306 replicate-0 cases; `sp120L` cases would not enter any cell). - **K2.3 Streams.** Plain windows `default_rng([seed, 0])` and cast windows `default_rng([seed, 1])` (GOAL.md 7.2); the rollout start positions of the plain windows, drawn by WM-2's `m1_gru.roll_positions` in the same call order as `losses_tf`, use a third stream `default_rng([seed, 2])` (WM-2 drew windows and positions from one `default_rng(seed)`; GOAL.md does not name the position stream). - **K2.4 Pooled `val_eff` rollouts.** The first cost check (code `bbae1a0c`) measured `val_t2` 7.4 s and `val_eff` 64.1 s, because `wm2.effects.model_predictions`' structure (kept by `effects3.predictions` for exact reproduction) makes one batched call per family and replicate (≈ 80 calls × 720 sequential steps). - **K2.5 V3 per-world score and the untrained head.** GOAL.md 8 asks V3 to use `judge_wm2.pw_verdict` on per-world scores; a world's V3 score is the mean over its W4 cases (both arms, both replicates) of |predicted − true split shift| in days (worlds without `sp240L` contribute their `gf240E` cases).
