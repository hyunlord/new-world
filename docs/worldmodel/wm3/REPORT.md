### 구현 의도
WM-2의 행동 인지 트랜스포머(M1b-act)는 신의 개입 효과를 "효과 없음"보다 잘 예측하지 못했고(W3 NONE), 개입 1시간 뒤의 반응조차 부호가 틀렸다(+240 먹이 증여 → +6 / −12 예측). 이것이 데이터·하네스의 버그인지 학습 문제인지 먼저 가리고(Part 1), 학습 문제라면 데이터셋 v2의 고유 자산인 **잡음을 공유하는 짝 갈래**(같은 세계·같은 복제본의 갈래와 사실 구성원)로 미세조정해 효과를 배우게 할 수 있는지를 사전 등록한 규칙으로 시험했다.

### 구현 방법
- **감사 A1 (데이터).** train·val 3,592개 사례에서 학습 경로(매니페스트 → `load_split` → `prepare`)로 갈래 구성원과 짝을 읽었다. 행동은 투입 행·종류 열에만 0이 아닌 값(요청량 / `ACTION_SCALE`)이고, 짝의 행동은 0이며, 투입 행까지 `x_state`·달력이 같고, 투입 행의 재고 차가 정확히 0인지 확인했다. 행동 확인: (c + 1의 갈래 − 짝 재고 차) / (부호 × 적용량)이 [0.5, 1.5]에 드는지.
- **감사 A2 (1스텝 응답).** WM-2 체크포인트 3개로 투입 행에서 끝나는 168행 창(롤아웃 예열과 동일)의 teacher-forced 평균 변화 μ × dstd를 갈래·짝 각각 계산해, 참 점프와 비교(평균, 상관, 부호 정답 비율).
- **감사 A3 (하네스 일치).** val 복제본 0의 306개 사례에서 `rollout_jobs`의 lag-1 차이와 A2 출력에 `Stepper.next_state`를 적용한 차이를 비교(허용 1e-4 × max(1, |s_c|) + 1e-3). 스텁 모델(먹이 μ = 행동 입력 × 120 / dstd) 단위 테스트.
- **위험도 헤드 모델.** `M1TFH`는 같은 최종 layer-norm 상태에서 `haz` 로짓을 낸다. WM-2 상태 사전을 `haz.*`만 빼고 strict 로드하며, mu / logvar / fire는 M1TF와 비트 동일(CPU 테스트, 그리고 모든 실행의 step-0 `val_t2`가 init과 일치).
- **투입 창 표집.** 배치 = 일반 창 16(`default_rng([seed, 0])`) + 투입 창 16(`default_rng([seed, 1])`, train 사례 2,980개에서 균등) + 짝 창 16. 투입 창은 c − 167 … c + 169 행이라 행동이 위치 167(롤아웃 시작의 마지막 teacher-forced 행)에 놓인다.
- **짝 차이 손실.** 투입 창과 짝을 같은 상태에서 168 스텝 굴려 |(cur_A − cur_F) − (true_A − true_F)| / std × 특성 가중치의 평균(화재 제외). WM-2의 teacher-forced·롤아웃 손실은 모든 창에 그대로.
- **위험도 손실.** 모든 teacher-forced 행에서 다음 시간의 분열(`g.fissions_total` +0.5 이상) BCE(양성 가중치 없음, 가중치 10).
- **미세조정 루프.** init의 `config.json`·`best.pt`를 읽고 정규화기를 같은 train 그룹에서 다시 맞춰 1e-12 이내 일치를 확인. AdamW lr 1e-4, k = 168 고정, 4,000 스텝, 250 스텝마다 평가, patience 6.
- **효과 인지 체크포인트 선택.** `val_t2`(WM-2 검증 T2 24 h) ≤ 1.05 × init인 체크포인트 중 `val_eff`(val 복제본 0, W3 3갈래 × 4결과 × {7일, 30일} 24셀의 척도화 효과 MAE, 720행 롤아웃)가 가장 낮은 것(init 포함). step-0 `val_t2`가 init의 `best_val_t2_24`와 1e-3 이내인지 확인(round_counts False, DECISIONS K2.1).
- **기대 분열일.** S_0 = 1, P_k = S_{k−1} h_k, S_k = S_{k−1}(1 − h_k), E = Σ P_k · day(c + k) + S_K · day(2,880). 분열 이동 = E_arm − E_factual. 분열 시점은 574행(25일 06:00)부터 E.
- **사전 등록.** 비용 점검(train·val만) 후 `eval_every` = 250을 정하고 `METRICS.md`를 어떤 시험 수치보다 먼저 커밋(`aa763da8`, 11:58:44). 모든 시험 평가는 `aa763da8` 워크트리에서 한 번씩만(덮어쓰기 거부) 실행.

### 기능 설명
- **WM-2의 실패는 버그가 아니라 학습 문제였다.** 행동은 올바른 행·값으로 모델에 들어가고(구조 불일치 0), 기록된 점프는 c → c + 1에 있으며, 하네스는 모델 자신의 1스텝을 부동소수점 정밀도로 재현했다(위반 0). 모델은 행동을 "보지만"(갈래와 짝의 출력이 다름) 실제 점프의 일부로만 반응한다(증여 3–8 %, `rot_wood` 목재 1–3 %, `sp240L` 10–19 %, `sp120L` 23–37 %).
- **짝 갈래 학습은 첫 1주일의 효과를 가르쳤다.** `wm3_full`은 7일 효과 오차를 출발 체크포인트 대비 0.096 줄였고(사후, [−0.122, −0.067]), 이는 더 학습한 덕이 아니라 짝 구성 덕이다(같은 선택 규칙의 `wm3_ctrl` 대비 −0.091, 투입 창만 넣은 `wm3_os`는 `ctrl`과 동률; `full`이 `os`에 더한 짝 손실·위험도 항·짝 창 16개는 분리하지 못했다). 그러나 사전 등록 규칙으로는 7일에서 최선 기준선 `an5_arm`과 동률(V2 TIE), 30일에서 "효과 없음"보다 나쁘다(V1 NONE). 30일의 실제 효과는 행동 반응으로 부호가 뒤집히는데(먹이 부패 → 30일 뒤 식량 +106), 어떤 모델도 이 반전을 배우지 못했다.
- **위험도 헤드는 분열을 "예측하게" 했지만 너무 이르고 보정이 나쁘다**(V3 TIE, V4 NONE; 30일 내 분열 예측 0.76–0.99 vs 관측 0.41).
- **논문이 주장할 수 있는 것**: 잡음 공유 짝 갈래가 있는 결정적 행위자 기반 세계에서, 사실 예측이 좋은 학습 세계 모델도 드문 개입의 효과를 무시하며 그 원인은 버그가 아니다(투입 창 비율만 올려서는 바뀌지 않으므로 "손실에서의 몫"은 가설일 뿐이다); 짝 차이 손실은 사실 정확도를 해치지 않고(V6) 첫 1주일의 효과를 배우게 한다. **주장할 수 없는 것**: 효과 예측이 단순 기준선보다 낫다는 것(V1 NONE, V2 TIE), 분열 예측(V3·V4), 1스텝 역학의 해결, 30일 효과.
