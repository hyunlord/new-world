# WM-1.1 구현 완료 보고

## 구현 완료 보고

### 구현 의도
WM-1의 168시간 성능(M1b 0.122)은 "한 단계 역학 모델을 굴린" 기준선(지속, ridge)에만 비교되어, 시드들이 거의 같은 궤적을 그리는 데이터셋 v0에서 "이 시기에 세계가 보통 어떤 모습인가"를 외운 것과 역학 학습을 구별할 수 없었다 → 기후학(climatology)·이상치 지속·유사 사례(analog) 기준선을 같은 하네스에 넣고, 시드 간 다양성을 재고, 사전 등록한 규칙(X1~X6)으로 M1b·M3·ridge·GRU를 다시 판정한다.

### 구현 내용
- **Part 0**: `GOAL_1_1.md` 커밋, RUNLOG/DECISIONS에 `## WM-1.1`, DGX 클론 detach, v1 매니페스트 5,012개 파일 존재 확인(누락 0, 매니페스트 밖 스케줄 JSON 224개), DGX에 `_build/v1src`(4c35e295) 클론.

- **Part 2** `diversity.py`(분할별 R²_abs·R²_year·η²·갈라지는 날·고정 시점 분산·severity 수열), `test_diversity.py`, `DIVERSITY.md`.

### 구현 방법
- **달력 기준선 9종**(모두 A_train 96개 에피소드의 V만으로 적합, 행 ≥ 24): CalAbs(행별 평균, OOD_long의 2,881행 이후는 1년(672행) 단위로 되감기), CalYear(연간 위치 평균, 절대시간 미사용), 이상치 지속 α=1(`ap1_abs/year`), 리드·변수별 최소제곱 α(`apfit_abs/year`), Lorenz(1969) 유사 사례(`an1`, `an5`, `an5_off`: 시험 창 24시간×8변수를 A_train split std로 정규화한 거리로 가장 가까운 에피소드를 찾아 그 뒤를 따라감; 창이 라이브러리 끝을 넘으면 1년 단위 한 번 이동). 모두 직접 예측(피드백 없음), 시작 행 s 이하만 읽고, 행동·severity·wood_target·latent·수명은 읽지 않음(단위 테스트로 확인). T4 효과는 정의상 0 = `zero_effect`.
- **검증 기반 선택**: 과제·지평별로 A_val·B_val 평균(T3는 A_val Brier, T3b는 MAE)이 가장 낮은 멤버가 `cal_best`, 절대시간을 읽지 않는 {CalYear, ap1_year, apfit_year} 중 최선이 `cal_best_fair`. 시험에서 재선택·재적합 없음.
- **다양성 지표**: R² = 1 − Σ(v − m)²/Σ(v − v̄)², η² = 행별 분할 평균 둘레의 제곱합 / 전체 제곱합(0이면 모든 시드가 같은 궤적), 쌍별 첫 차이 행(>1e-9)의 표시 일자, 30·60·90·118일 06:00의 시드 간 표준편차/split std, 각 겨울 첫날 18:00의 severity 수열과 같은 수열 그룹 내 η²(설명용, 입력 아님).
- **사전 등록**: 검증 실행(`calendar_val_dfec0bdd`, `diversity_v1_dfec0bdd --val-only`) 뒤, 어떤 신규 시험 점수보다 먼저 `METRICS_1_1.md`를 `9f4fd3f3`(11:07:28)로 커밋. 이후 수정 2건은 날짜 있는 수정 기록(OOD_v12 severity 처리; v1 시험 분할 서술 진단이 사전 등록 전에 계산되었다는 사후 공개).
- **M1b 추가 시드·sev-on**: WM-1이 기록한 명령에서 시드와 출력만 바꿔 GPU에서 두 개 병렬 학습; sev-on은 `--variant sev-on_action-aware --seed 0`.
- **M3 day 제거**: 같은 레시피·시드(같은 샘플 순서)·4스레드 CPU, `--max-steps 276`(M3의 `steps_done`), `--max-seconds 28800`(단계 수가 제약이 되도록).
- **v1 진단**: v1src의 `bench_v1.load_split`·`split_std`·`nmae`·`rollout_starts(every_hour=True/False)`로 같은 지표와 달력 기준선, `bench_v1.json`의 ridge와 비교.

### 기능 설명
- **확정된 것**: v0에서는 달력(유사 사례)만으로도 24시간·168시간 예측이 WM-1의 모든 M1/M1b/ridge 모델보다 낫다(M3는 24시간에서 예외). 사전 등록 판정: **M1b 168시간 X2 = NONE**(`cal_best` 대비; 절대시간을 쓰지 않는 공정 기준 대비로는 WEAK), **X3 = NONE**(두 기준 모두), **X4 = M3와 M3-noday 모두 "달력 암기와 구별되지 않음"**, M3 − M3-noday = +0.0008(절대 날짜는 기여 없음), **X5 = ridge_nosev·M1 GRU 모두 NONE**. v0 시드는 1일차부터 갈라지지만 차이가 작아(A_test η² ≤ 0.05: 나무·불·인구·고사목, 식량 0.085) 달력 평균이 분산의 95% 이상을 설명한다.
- **사후(사전 등록 규칙 없음)**: 이번 겨울의 severity와 현재 나무에 달린 사건 과제에서는 M1b가 대체로 달력보다 낫다(T3 Brier 세 시드 모두 우세; T3b는 A_test·OOD_long에서 세 시드 모두 우세, B_test·OOD_v12에서는 시드 2가 열세).
- **연구 계획(데이터셋 v2, Pass 9–10)에 주는 의미**: v0 벤치마크로는 24~168시간에서 "역학 학습"을 주장할 수 없다. M1b가 넘는 것은 공정 기준(연중 위치)뿐이고 그 차이도 KEEP 기준(0.8×)에 OOD_long에서만 닿는다. 데이터셋 v2는 시드 간 다양성을 구조적으로 늘려야 한다(키별 난수, 같은 상태에서의 fork, 잠재 변수 재표본, 시작 상태·시작 달력 시점 다양화). 휴리스틱 목표: 재고·인구 변수 η² ≈ 0.3–0.5 이상, 달력 평균 R²_abs ≈ 0.5–0.7 이하. v1(game_v14)은 식량 다양성만 약 2배로 늘렸고(η² 0.085→0.195) 나머지는 그대로라, v1에서도 달력이 ridge를 약 2배 앞선다.

- **M1b의 168시간 성능은 역학 학습인가, 달력 암기인가?** v0에서는 "역학 학습"이라 부를 수 없다. 사전 등록 규칙으로 X2 = NONE: 세 시드 평균이 검증으로 고른 유사 사례 기준선(이 세계의 평소 궤적을 따라갈 뿐인 예측기)보다 모든 셀에서 21–53% 나쁘다. 절대시간을 읽지 않는 공정 기준보다는 8–26% 좋아(WEAK) 7일 문맥에서 연중 위치 이상의 정보를 쓰고 있지만, 그것이 역학인지 궤적 맞추기인지는 v0로 구별할 수 없다. 단기(T1·24시간)도 X3 = NONE. 반면 이번 겨울의 상태에 달린 사건 과제(T3, T3b)에서는 대체로 달력보다 낫다(사후) — 상태를 쓴다는 가장 분명한 신호다.
