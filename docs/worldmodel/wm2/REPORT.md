## 구현 완료 보고

### 구현 의도
WM-1.3까지는 학습 모델이 사실(factual) 세계를 달력·유사 사례 기준선보다 조금 더 잘 예측한다는 것만 확인됐다. 하지만 그것이 소음 바닥에 얼마나 가까운지, 그리고 신의 개입(먹이 증여·부패·목재 썩힘)이 무엇을 할지 예측할 수 있는지는 몰랐다. 그래서 `game_v19`에서 개입 가족·반복 분기·소음 바닥 세트로 데이터셋 v2를 기록했고, 사전 등록한 세 질문을 시험했다. 질문은 (1) 바닥까지의 거리, (2) 개입 효과 예측, (3) 긴 기억으로 분열을 미리 아는가이다.

### 기능 설명
- **확인된 것**
  - `game_v19` 사실 예측은 바닥에 닿지 않았다. headroom은 168 h에서 ≥ 0.059로 하한 추정이다. 다만 이 바닥은 전체 상태를 아는 예측기 기준이다.
  - 학습 변환기(M1b-act)는 매시 시작점에서 검증 선택 유사 사례 기준선보다 5–10 % 낫다(WEAK). 06:00 바닥 시작점에서는 오히려 진다.
  - 가장 중요한 결과: 학습 모델은 신의 개입이 무엇을 할지 **"효과 없음"보다 잘 예측하지 못한다**(W3 NONE).
  - 분열은 한 번도 예측하지 않는다(W4는 `an5_arm`과 TIE이며 예측은 0 예측기와 동일, W5 NONE). 긴 기억(GRU 전체 이력)도 바꾸지 못한다(W5b는 [0, 0]의 퇴화 동점).
  - 검증 진단(사전 등록 아님): 모델은 개입 1시간 뒤의 기계적 효과조차 거의 학습하지 못했다. 240 증여 시 실제 +237, 예측 +6 ~ −19. 굴린 `fissions_total`은 96일 동안 최대 0.0006 / 0.11만 오른다.
  - 원인 가설(진단과 부합하지만 절제 실험으로 검증하지 않음): 개입 행이 학습 행의 0.03 %이고, 분열은 2,880행 중 단 한 번의 +1 계단이다. 중앙값을 좇는 L1 항이 있는 다음-시간 예측기는 이를 잡음으로 취급한다.
- **논문이 주장할 수 있는 것**
  1. 인과적·반사실적 예측을 위한 벤치마크(대응 개입 가족, 복제본, 바닥 세트, 동일성 검증)와 그 데이터 안에 크고 규칙적인 단기 효과가 있다는 것.
  2. 사실 예측이 포화되지 않았다는 것.
  3. 학습 세계모델의 사실 예측은 매시 시작점에서 강한 기준선보다 조금 낫다는 것(WEAK).
  4. 같은 모델이 행동을 입력으로 받아도 개입 효과와 분열을 학습하지 못한다는, 기전이 붙은 부정적 결과.
- **주장할 수 없는 것**
  - 학습 모델이 개입 효과를 예측한다는 것.
  - 긴 기억이 분열을 미리 본다는 것.
  - 예측이 바닥 근처라는 것.
  - KEEP 수준의 사실 예측 개선.
  - WM-1.3의 `game_v16` 168 h 우위가 새 세계에서 재현된다는 것(W6 TIE, 1시드: 0.210 vs WM-1.3 0.194).
  - 관측 이력만 보는 예측기가 바닥까지 갈 수 있다는 것(바닥은 전체 상태 바닥).
