## 구현 완료 보고

### 구현 의도

WM-5는 v2 테스트에서 벤치마크에 여유가 있음을 측정했다(7일: `zero` 0.612, 잡음 바닥 0.187). 그러나 평가된 어떤
방법도 그 여유를 쓰지 못했다(`ridge_obs` 0.480, `ridge_priv` 0.434, CRN 1.649, CT 1.243). 심사자가 다음에 물을
질문은 "0.434와 0.187 사이의 간격은 **학습 가능한가**, 아니면 세계별 개입 효과가 상태가 주어져도 사실상 혼돈적인가"이다.
WM-6은 이 질문에 학습 곡선으로 답한다. 반사실 학습 세계를 5배(400 → 2,000)로 늘리고, 개입 직전 상태의 비선형 직접
효과 모델(관측·특권)을 중첩 집합 N = 400, 800, 1,600, 2,000에서 학습했다. 그 결과를 사전 등록한 해석 규칙으로 판정하고
논문에 반영했다.

### 구현 방법

- **새 반사실 세계 녹화와 동질성 검사.** 동결된 WM-2 레코더(`_build/src_wm2`, 재빌드 없음,
  `WORLDSIM_GIT_SHA=f5373ab2…`)로 `game_v19` 시드 50000–51599를 녹화했다. 플래그는 WM-2의 v2 학습 세계와 같다
  (타임라인 시계 목록, `--check-determinism`, `timeline_p14`/`schedules_p14`, 네 팔, 포크 14,280, factual 포함).
  다른 점은 R = 1 하나다. 세계당 레코더 호출 1회는 WM-2 구성원을 비트 단위로 재현한다(시드 40000 스모크). 그래서
  학습이 시작되면 워커 수를 8에서 4로 바로 줄일 수 있다(L1.1–L1.3). 검증 결과는 다음과 같다.
  - 16개 청크 모두 DETERMINISM PASS.
  - 7,576개 에피소드 전부 sha 검증.
  - 1,600/1,600 가족이 접두 검사를 통과했다.
  - 동질성: 40개 KS 검정(팔×결과×지평의 참 효과, 개입 행, 분할 이동)에서 최소 p 0.066, 최대 D 0.078.
- **중첩 학습 집합.** 학습 집합은 N = 400(WM-2의 40000–40399)부터 시작해 50000–50399, 50000–51199, 50000–51599를 차례로
  더한다. **복제 0만** 쓰므로 곡선을 따라 바뀌는 것은 N 하나뿐이다. 검증은 v2 val(양 복제), 테스트는 v2의 80세계
  604사례(양 복제)이고, 둘 다 바꾸지 않았다.
- **비선형 직접 효과 모델.**
  - 공통: 팔 원-핫 입력, 8개 출력(결과 4 × 지평 2), 지표 그대로의 손실(척도화 효과의 마스크 MAE),
    v2 val 24셀 평균 조기 종료.
  - **MLP**: 3층, GELU, AdamW, 그리드 {256, 512} × {0.1, 0.3}를 N = 400에서 한 번 고르고 모든 N에 고정했다.
    관측 512/0.3, 특권 256/0.3.
  - **GRU**: 2층 128, 행위 직전 168행의 WM-2 74개 관측 입력을 읽는다. 마지막 상태를 특징과 이어 같은 헤드에 넣는다.
  - **GBM**: LightGBM, 셀별, L1. 별도 venv에 `--no-deps`로 설치했다(L2.7).
  - **ridge**: WM-5 코드를 N마다 다시 적합했다.
  - **특권 변형**: 숨은 필드를 추가한 것으로, 진단용이며 순위에 넣지 않는다.
- **사전 등록된 해석 규칙.** METRICS.md(`f1777fb5`, 00:59:27)는 첫 학습과 WM-6 모델의 모든 테스트 산출·저장된 테스트 특징보다 먼저 커밋했다(L3.1).
  - 닫힘 = (`zero` − 모델)/(`zero` − 바닥).
  - "관측으로 학습 가능" = C1 모델의 7일 닫힘 ≥ 0.5, 또는 C4 기울기 CI 상한 < 0이면서 닫힘 ≥ 0.35.
  - 그다음 "숨은 상태로만", "이 규모에서 학습 불가", "부분적" 순으로 판정한다.
- **논문 갱신.** 해석이 허용하는 만큼만 문장을 바꿨다. 모든 새 수치는 `judge6/judge.json` 또는
  `describe/describe.json`의 자리표시자로 넣었다(L6.3).

### 기능 설명

- **여유는 학습 가능한가? — 부분적으로, 그렇다.** 사전 등록 해석은 **"관측으로 학습 가능"**이고, 두 번째 조항으로
  성립했다. C1 모델 `mlp_obs`는 2,000세계에서 7일 간격의 **0.449** [0.38, 0.52]를 닫는다. 이는 0.5에는 못 미치지만
  0.35 이상이다. 기울기는 배당 **−0.0080** [−0.0121, −0.0034]이고 CI가 0 아래에 있다. 이 CI는 테스트 세계만
  재표집한다(리뷰 1차 M1). 사후 분석에서 시드별 기울기는 −0.0158, −0.0023, −0.0058이다. 시드 0을 빼면
  −0.0040 [−0.0078, +0.0001]로 0을 포함한다. 세계와 시드 분산을 모두 넣은 정규 구간(시드 분산은 불편 추정)은
  −0.0080 [−0.0170, +0.0011]이다. 즉 3시드에서는 결정 조항이 시드 변동에 견고하지 않다(리뷰 2차 M1). 그래서 리뷰 뒤
  사후로 `mlp_obs`·`seq_obs`의 시드 3–9를 모든 N에서 더 학습했다(규칙은 시드 0–2 그대로). 10시드에서 `mlp_obs`의
  기울기는 두 분산을 모두 넣어 −0.0083 [−0.0133, −0.0034]이고 닫힘은 0.452 [0.38, 0.52]다. 따라서 조항 2의 조건은
  10시드에서 성립한다. `seq_obs`의 10시드 기울기는 더 작다(−0.0042 [−0.0091, +0.0006]).
- **관측 상태로?** 그렇다, 7일은 일부만. 비선형 관측 모델(MLP, GRU, GBM)은 모든 N에서 선형 관측 지도를 이기고, 이미
  400세계에서 닫힘이 0.41이다. 관측 모델 셋은 2,000세계에서 0.412–0.422로 서로 가깝다. 지난주 시간별 이력(GRU)이 더하는
  것은 거의 없다. 30일은 관측 모델이 `zero`를 겨우 넘는다(닫힘 0.07).
- **숨은 상태가 필요한가?** 남은 것의 약 절반에 필요하다. 특권 MLP는 7일 닫힘 **0.72**이다(C6: −0.115
  [−0.158, −0.079]). 관측 모델이 놓친 1주 간격(0.235)의 약 49 %를 되찾는다. 특권 모델의 30일 닫힘은 0.11 → 0.42로 오른다.
  셀별로 보면 그 이득은 부패(spoil) 개입의 인구·정착지 셀에 있다. 아마도 분할을 일으키는지 여부일 것이다(사후 추정,
  검증 안 됨).
- **데이터를 늘리면 바닥에 다가가는가?** 느리게 다가간다. 관측 모델은 400 → 2,000에서 −0.017(`mlp_obs`), −0.012
  (`seq_obs`)이고 둘 다 WEAK이다. 1,600 → 2,000 구간은 0.32배에 불과해 시드 잡음 안에서 판단할 수 없다. 특권 모델은 약 3배 빠르다(배당 −0.027). 외삽은 하지
  않는다.
- **논문의 결론은 무엇으로 바뀌었는가?** WM-5까지는 "여유가 있다, 그러나 아무도 못 쓴다"였다. 이제는 "여유의 일부(약
  45 %)는 관측 상태에서 학습 가능한 측정된 목표다"가 된다. 사후 비교로 보면, 직접 모델은 v2 규모(400세계)에서 이미
  `an5_arm`(−0.047 [−0.081, −0.012])과 `wm3_full`(−0.058 [−0.112, −0.018])을 이긴다. 따라서 동역학 모델과 CRN·CT의
  실패는 관측 상태의 신호 부족만으로는 설명되지 않는다. 남은 1주 간격의 약 절반은 숨은 상태를 더하면 회복되고, 여기서 평가한 관측 모델(2,000세계까지)은 1개월 효과를 거의 배우지 못했다. 초록 (v), 서론의 네 번째
  질문·기여, 새 결론(§7)이 이 내용을 담는다.
