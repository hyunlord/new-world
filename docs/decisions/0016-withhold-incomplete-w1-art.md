# ADR 0016: Withhold incomplete wall families from runtime import

## Context

W1 requests thin interlocking log walls and complete/construction hut roofs. The art-only branch cannot change runtime code. Three attempts per failing piece did not establish consistent NS projection and corner continuity; both construction frames fail frozen numeric checks. The inspected Godot baker also cannot express the full-piece topology through its current data schema.

## Decision

Retain four individual built-roof/EW-door cut-outs as blocked candidates, with zero full adoptions. Preserve all originals and measurements outside Git. Commit explicit rejected contact sheets, provenance, a complete attempt ledger and disabled additive import proposals. Describe the generic 16-mask renderer capability in `art/batch_w1/RENDERER_HANDOFF.md`; do not add style-name branches or pretend the schema already supports it.

## Alternatives considered

- Adopt readable frames despite failed wash flatness: rejected because it changes the frozen acceptance criterion.
- Continue generating under renamed pieces: rejected because it exceeds the three-attempt cap.
- Import the four isolated candidates immediately: rejected because model evaluation, placement and door registration remain unverified; the hide roof leaves square-ring corners exposed.

## Consequences

The requested coherent set remains incomplete. Integration can reuse the four candidates only after resolving their recorded blockers. Runtime schema/parser/resolver changes and fresh family generation require a later authorized pass. No simulation identity claim or runtime test claim is made.
