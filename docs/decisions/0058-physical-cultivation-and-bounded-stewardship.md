# ADR 0058: Physical cultivation and bounded stewardship

## Context

M6b Stage 0 stopped under owner D-S0-2; the existing M-LOOP/M-READ gate remains the publication path. Stage 1 must add farming and repair the failed stewardship work without another gate framework. Eight BASE worlds measured before implementation produce 551–1183 raw-edible wild plant units per display-year. Gross wild production does not establish dependable intake, and a deficit-only farm planner would often never plant.

## Decision

Use data-defined crop identities, physical seed inputs and atomic multi-output harvests. Fields use the existing command, job, navigation, reservation and mind execution paths. Keep the eight work priorities; cultivation initially uses Haul. Soil remains attached to the tile through designation removal, and established crops remain real after erasure. Daily frost or covering can fail a crop without creating output or refunding consumed seeds. Presentation reads state and sends explicit ordinary commands; card expiry sends none.

Plan an initial 30% replacement share from annual adult/child demand, with authored winter consumption included. At an assumed effective net yield of twelve edible units per tile, ten/twenty/forty warm adults need seventeen/thirty-three/sixty-five planned tiles; floor the 1.25 area cap to twenty-one/forty-one/eighty-one. These are first calibration values, not held-out findings. Seed retention constrains steward-owned finite cooking batches, while explicit player bills and emergency intake retain their paths.

Bound proactive wild harvest and cooking by one edible reserve budget, with a separate durable winter horizon. Accepted work is counted once and cancelled work is not supply. Build an actual roofed Storehouse through the existing blueprint/completion path before proactive surplus collection. Separate construction logs from the physical log-to-firewood recipe and executable fuel supply. Survival tool production remains immediate and does not inherit seasonal fuel or grace gating. Teaching uses real teacher/order lifecycles.

Count field intake only at completed meals. Carry outward-rounded integer fractions through physical transfer, split/merge, cooking and delayed output. Mixed recipe attribution is proportional to nominal food-input units, not a claim about individual grain identity. Food converted into durable nonfood seeds is a real craft-input sink; sowing consumes physical seeds without claiming eaten food. A tended emmer harvest splits into ten grain and two retained seeds. Durable seed avoids the carried-grain expiry boundary between summer harvest and next spring. Blocked seed output retains the working craft until placement succeeds; cancelled seed carriers keep their load for retry, and unplaceable loads on death record an explicit seed loss and ledger consumption. Persist this state in an explicit format16 tail and retain an exact format15 reader; old food has known zero cultivated contribution. Append command, job and mind-order variants rather than changing old discriminants.

Correct #675 at the real daily expiry boundary: the same living settlement member must be awake, above the actual seek threshold, and lack actionable reachable edible food. Compare an instrumented BASE whose existing outputs remain identical before adopting a discriminatory bar. Zero/zero is diagnostic. Reuse the existing M6a summary for these concrete metrics; no new observer or receipt hierarchy is introduced.

## Alternatives considered

- Add crops only when wild food is insufficient: rejected because measured gross wild supply would suppress adoption.
- Credit crop harvest as field intake: rejected because spoilage, seed use and mixing would falsely satisfy the owner's meal-share bar.
- Repaint to reset soil or refund seeds on cancellation: rejected because both create resources without physical work.
- Instant sowing cards or passive expiry orders: rejected because presentation must use normal validated commands.
- Serialize new fields into historical positional payloads: rejected because serde defaults cannot recover an old bincode layout.
- Resume the generic gate expansion: rejected by D-S0-2 and D-S0-4.

## Consequences

New gameplay deliberately changes colony outcomes, while the baseline simulation remains an identity gate. Migration, physical item conservation, deterministic continuation, crop data-only extensibility, actual UI interaction, calibration, held-out bars and the legacy full gate must pass before publication. This ADR records the implementation decision; it does not claim those validations have completed.
