# ADR 0003 — About ten founders

## Context
V7 worlds started with 20–30 residents. The new loop is about growing a settlement and spreading knowledge between people.

## Decision
A game starts with about 10 founders; the population grows by birth and migration (ADR 0006).

## Alternatives considered
Start at 30 (rejected: the early game is about learning each person).

## Consequences
Worldgen's founder count changes in M1. Small isolated groups lose complex skills (Henrich), so migrants are part of v1.0.

2026-10-20
