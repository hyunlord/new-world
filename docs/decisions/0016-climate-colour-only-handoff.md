# R2: deterministic colour-only climate art handoff

## Context

B2 flora and grounds were too pale beside shipped concept05 art. R2 requires
unchanged shapes, canvases, anchors and footprints, with recorded colour targets.
B2 already rejected all new grounds and blocked olive anatomy/species adoption.

## Decision

Use pinned shipped family/state controls and deterministic monotone HSV quantile
transport. Keep matching shipped tree seasons pixel-identical. Preserve alpha and
hidden RGB exactly. Disclose nearest-habit controls where no shipped crop exists.
Separate colour measurements from inherited style, seam, anatomy and model gates.
Keep failed grounds and olives outside active additive import drafts.

## Alternatives considered

- Regenerate: rejected because colour can change without redrawing frozen shapes.
- Universal saturation boost: rejected because families and seasons need different
  hue, saturation and value targets.
- Lab canopy-only olive correction: improved hue but left the value distribution
  outside the control; recorded as a superseded attempt.

## Consequences

67 active art candidates (41 corrected and26 reused seasons),12 blocked olive
proposals and8 blocked ground reviews. No runtime selectors or materials added.
No simulation identity claim or game integration claim is made by this art pass.
