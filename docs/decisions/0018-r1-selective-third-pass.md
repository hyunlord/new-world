# R1 selective third-pass budget and readiness

## Context

BRIEF5 authorizes four more attempts for seven gaps in four nearly complete
wardrobes. Pass 2 accepted 58/84 bodies, with no twelve-body wardrobe.

## Decision

Extend ADR 0017 only for the seven named gaps: total ten attempts, including
prior attempts and deterministic transforms. Leave the other three wardrobes
and every historical asset unchanged. Record failed ratios and a different
approach before each retry. Keep measurements, masks, normalization, structure
and actual 1×/2× visual threshold unchanged.

Hair-only editing must preserve the crown extent because the frozen idle-height
normalizer scales the whole body. Use real tied hair rather than a renamed bun.

Twelve accepted bodies authorize missing portrait production and the draft top
list. Reuse valid historical portraits. All six FACE_VARIANTS identities remain
ordered and hash-bound. Portrait readiness requires twelve complete six-variant
sets; a missing set is explicit and blocks downstream integration readiness.
Parchment portrait raws are opaque; transparent bodies use a different output
background flag. Failed calls consume the existing three-call portrait budget.
No runtime data, appearance indices or importer is changed.

## Alternatives considered

- Extend all wardrobes: rejected because approval is limited to seven gaps.
- Relax outline thresholds or alter idle normalization: rejected by frozen gates.
- Flatten failed alpha or alias missing portraits: rejected because it conceals
  actual tool output and missing identity art.

## Consequences

A complete body wardrobe may still have incomplete portraits. Both states and
all rejected trials remain visible; drafts are proposals pending game validation.
