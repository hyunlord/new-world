## 구현 완료 보고

### 구현 의도
마을 사람들이 모두 똑같이 움직이던 문제 → 사람마다 타고나 일부는 부모에게서 물려받는 기질(4축)을 주고, 그 기질이 일상의 네 가지 선택을 기울게 해서 "사람마다 다른 마을"을 만든다(게임 트랙의 첫 패스, 새 장면 `game_v20`; 연구용 `game_v19`와 그 이전 장면은 비트 단위로 그대로).

### 구현 내용
- **기질 구성요소** `Temperament { ns, ha, rd, p }`(퍼밀 0–1,000, 평균 500; Cloninger의 새로움 추구·위험 회피·보상 의존·인내력). 설립자는 계보 키로 추첨, 신생아는 부모 둘의 중간값에서 유전율 0.5로 물려받음. `Hardiness`를 넣는 바로 그 자리(설립자 `camp.rs`, 신생아 `settlement_system.rs`)에 삽입.
- **규칙** `AgentRules::temperament: Option<TemperamentRule>` — 이번 패스에서 기존 공개 구조체에 추가한 유일한 필드(이전 모든 장면에서 `None`).
- **장면** `game_v20`(= `game_v19` + 기질 효과)과 위약 `game_v20_inert`(기질은 뽑아 저장하지만 효과 없음 = `game_v19`와 동일).
- **네 가지 기울기와 분열 이탈**: NS → 한가할 때 배회 반경(어른의 기본 묶임 반경 8 → 4…12칸), HA → 취침 시각(21:00 → 20:00…22:00, 그 사람의 밤 창 전체), RD → 외로움 증가 속도(0.04 → 0.02…0.06/틱), P → 집으로 나르기 전에 채우는 짐(음식 4 → 1…7, 나무 2 → 1…4, 일꾼만), NS → 마을이 갈라질 때 떠나는 순서(가중치 1,000).
- **개인 추적** `worldsim_probe --agent-trace`(기본 꺼짐; 켜도 기존 출력 바이트 동일): 사람마다 기질과 비노인 성인 시간 동안의 배회 거리·취침 분·사교 완료·운반량·이탈 여부를 기록. `game_v19`에서는 기질이 있었다면 가졌을 값을 계산만 하고 넣지 않음.
- **브리지 게터** `get_agent_temperament(entity_bits)` → `{found, ns, ha, rd, p}`(`get_agent_detail`의 9개 키는 그대로). 실제 게임(`init`, `reset_world`)은 `game_v20`, `reset_world_stress`는 `game_v19` 유지.
- 보조: `worldsim_perf --rules game_v19|game_v20|game_v20_inert`, `evaluate_pass16.py`(+ 테스트 8개), `gate_pass16.sh`, `quiet_lock_p16.sh`(맥 공유 잠금), `dgx_probe_p16.sh`, `identity_p16.sh`, `perf_p16.sh`, 문서 `TEMPERAMENT.md`.

### 구현 방법
- **추첨**: 설립자 축 a = (u1+u2+u3)/3, `u_s = keyed_below(seed, STREAM_TEMPERAMENT, key, 0, 4a+s, 0, 1001)`(평균 500, SD ≈ 167, 복제본 0이라 노이즈 포크가 다시 뽑지 않음). **유전**: `fresh = founder(seed, child_key)`, 중간값 mid(부모 둘의 정수 평균, 하나면 그 값, 없으면 fresh), `clamp(500 + (mid−500)/2 + (fresh−500)·935/1000, 0, 1000)`(i32; 0.935 = √(1−0.5²/2)로 세대 간 분산 유지). 단위 테스트: 20,000키 평균 500±5·SD 167±5, 기울기 0.45–0.55, 자식 SD 167±10.
- **사람별 값**(d = 축 − 500, i32 나눗셈은 0쪽으로 절삭): 묶임 `max(2, 8 + 4·d/500)`, 취침 `1260 − 60·d/500`, 외로움 `0.04 × (1000 + 500·d/500)/1000`, 음식 짐 `clamp(4 + 3·d/500, 1, 8)`, 나무 짐 `clamp(2 + 2·d/500, 1, 8)`, 이탈 키 `단위난수 − 1000·ns/1,000,000`. 모두 `sim-core`의 순수 함수, `effects: false`이면 기본값. 금지 수학 없음.
- **최종 폭**: NS 4칸, HA 60분, RD 500‰, P 음식 3 / 나무 2(조정 2라운드에서 2/1 → 3/2), 이탈 가중치 1,000.
- **`haul_threshold` 사용처 분류**: 생산 경로(사람별, 일꾼만) — 의사결정 건축가 확인 L699(음식)·L701(나무), `loaded` L1031·L1032, 채집 `light` L1503, 땔감 `light` L1528, 줍기 `bounded` L1560, 나무 줍는 양 L2039, 이동 `hauls_home` L110·L130–131. 테스트 고정값(손대지 않음) — `firewood.rs` L325, `movement.rs` L398, `agent_decision.rs` L2499.
- **HA 배선**: 그 사람의 밤 창(취침 시각~06:00)을 계산하는 순수 함수 `person_night_rest`와 클로저 `rest_for`; 시계로 거른 모든 밤 읽기(건축가 질의, 사교 적격, 동료 지도 두 개, 본 루프 전체와 `Consuming{Sleep}` 분기)에 적용하고, 거르지 않은 읽기(L1852, L2260, L2271, `beds.rs`)와 탐침의 `fatigue_threshold_at`은 그대로. 일찍 잔 사람이 20:00–21:00에 깨었다 잤다 하지 않음을 단위 테스트로 확인.
- **동작 불변 증명**: (1) 다른 Rust 변경 전에 `game_v19`/`game_v19_nofission` 고정값을 단독 커밋(`1362addd`; 시드 0–4, 1,440·40,320틱 지문·다이제스트, 규칙은 필드별 `assert_eq!`), (2) I1–I3(32세계×120일 요약, 녹화기 배열 sha256)이 기준 `da8e45c7`와 동일 — Part 2(`7ee8b86c`)와 최종 커밋(`9eb221d3`) 두 번, (3) inert = v19: 40,320틱 지문·다이제스트(시드 0–4, 테스트) + 120일 요약 32세계(DGX, `7ee8b86c`와 `9eb221d3` 두 번, 차이는 `scene` 이름뿐), 평가 시드에서도 동일, 500명 스트레스 세계에서도 같은 지문.
- **관찰자 계측**: 시스템을 바꾸지 않는 틱 후 관찰자(`probe/agent_trace.rs`). 비노인 성인 시간만, 시스템 틱의 시계, 소속 마을의 화덕 기준. v20에서는 계산값과 구성요소를 대조(불일치 0), `AgentBorn` 사건 누락 0. 손으로 계산한 스크립트 엔진 단위 테스트.
