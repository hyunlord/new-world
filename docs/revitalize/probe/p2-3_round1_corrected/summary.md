# game probe summary

Seeds: 0..64; samples every 120 ticks.

Quantiles use linear interpolation. Day checkpoints are exact even when the sampling interval does not divide a day. Idle breach share is cumulative sampled breaches / sampled agents (including tick 0). Performance uses primary-engine tick wall time minus measured read-only census observer time / exact pre-tick agent count sum; run wall time includes census, I/O and optional twin validation. Agent-days integrate every pre-tick living count; social rate counts completed interaction pairs per agent-day. Idle actionable uses the decision actionable_need helper and rule-aware NeedAvailability (hunger, thirst and fatigue). Idle unavailable independently means a survival need is breached but none of its matching resource tiles has positive supply. Legacy rules force helper availability true, so these two counts can overlap under legacy rules. Old idle_with_breach remains hunger/thirst only.
