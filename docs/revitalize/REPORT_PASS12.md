### 구현 방법
- **새 다양성 지표(R²_static·UBS)와 옛 데이터 재채점**: 날 d∈{30,60,90,118}의 변수 평균 y_e를 숨은 파라미터(기후는 원-핫) + 3–10일 평균 m_e로 릿지 회귀(λ는 {0.1,1,10,100,1000}에서 LOO MSE로 선택), LOO 예측으로 R²_static과 UBS = RMSE / S_j(행 ≥24 전체 표준편차). 합성 시험: 선형 정적 세계 UBS < 0.05, 10일 뒤 독립 랜덤워크 UBS > 0.3, **10일 뒤에 나타나는 2차 정적 효과는 UBS 0.970**(선형 릿지가 비선형 정적 효과를 "설명 안 됨"으로 센다 — 이 한계를 아래 판단에 반영). 옛 데이터: v17 alive UBS 0.881(v16 0.309) — 그러나 v17의 "분열 여부"는 29일째 인구의 문턱 함수(비선형 정적 효과)라 역사로 읽으면 안 됨.
- **딸 마을 진단**: Pass 11 최종 96개 세계 + 재녹화. 굶어 죽음 20건 전부 덤불 부족 지역(17건은 덤불 0개), 탈수 38건(지역 중심의 물 거리 중앙 21), 지역 중심 밖 설립 0건, 0.35 초과 정착지-겨울 45건 전부 딸 마을(겨울 시작 장작은 정상, 겨울 동안 소진).
- **오후 노동 이분 탐색**: 지역 덤불 하나가 격차 전부를 설명(되돌리기 1.000, 추가 1.107, 장작만 0.000). 빼앗긴 활동은 채집(15시 성인 채집 0.178 → 0.128). 경로: 캠프 반경 끝에서 일하는 사람이 Gather 팔로 지역 덤불 식량을 주워 와 저장고가 목표를 넘고(15시 행의 93 % vs 82.5 %) 채집 팔이 꺼진다.
- **분열 위험도**: 7.1의 정수 공식 그대로(g·q·s·h, 천분율), `keyed_below(seed, STREAM_FISSION_HAZARD, sid, tick, 0, r, 1000) < h`, r = 그 시점의 잡음 복제본. 계절 문은 `allowed_seasons`(v18: 봄·여름·가을). 위험도는 수용력 다음, 장소 선택 전에 붐빔 문을 대신한다. 모든 검사를 `fission_checks`에 기록(측정 전용).

### 기능 설명
- **게임**: 마을은 이제 붐비거나 식량이 모자랄수록 매일 아침 갈라질 확률이 오른다. 첫 분열은 12일부터 114일까지 퍼지고(보류 시드 중앙 38일, IQR 38일, 가장 흔한 날이 11 %), 가을에 떠난 무리도 첫 겨울을 넘긴다(딸 마을 28일 생존 100 %). 딸 마을은 약속된 덤불을 실제로 받고 물 가까이에 선다. 비는 이제 그날 밤 장작을 태우면서도 불을 지피지 못한다(포크 실험: 비 시간 동안 저장 장작 감소 35.0 대 맑은 밤 35.7). 라이브 게임은 `game_v18`로 시작한다.
- **연구**: 분열 시점이 세계마다 달라졌다(v17: 29일에 70–81 %). 그러나 시점을 움직이는 것은 주로 위험도 추첨의 잡음이고, 신의 작은 개입은 거의 움직이지 못한다(거시 민감도). UBS는 v17보다 커지지 않았다(J7b 실패).
