Changes: `capture_framings.gd`, `test_capture_pair_p8.gd`, and the pacing clarification in `FRAME_MEASURE_README.md`. No staging or commit by this slice.

- F2W uses camera zoom 2. Paired shot options are the optional dictionary at index 8: `paired_world`, `case_id`, `role`, `stem_override`; index 7 remains the target. A stem override receives the normal `god_` prefix. RESET remains `["RESET", seed]` and increments `world_epoch`.
- Manifest top-level `intervention_casts` retains all casts across resets. Capture rows and entity sidecars retain only the current world's casts and export `world_epoch`, `world_label`, and `capture_options`.
- Each cast exports `precast_original`: actual original settlement ID/found flag, food, members, adult daily need, scarcity days/line, below-line flag, pressure, threshold, time snapshot and need provenance. Each sidecar additionally exports `original_settlement_observation` at the frame tick. Final sidecars retain the existing actual `society_snapshot.fission_depart_ticks`.
- Adult need is derived from the checked Rust `adult_need_per_day` expression, `HUNGER_CONSUME_AMOUNT`, `V19_HAZARD.scarcity_days`, and live `get_world_info().ticks_per_day`. Source paths and SHA256 values are recorded; no guessed parameter or simulation modification. A33 fails explicitly if these source patterns no longer match.
- An unavailable paired target records `reply.ok=false`, `applied=0`, a reason, and `input_surface="not invoked: missing paired target"`; it does not invoke a panel command or fabricate effects. Other capture contracts remain strict. Missing paired framing falls back to the observed village view so evidence can continue.
- Legacy `_measure_frame_times` now awaits process frames and explicitly draws the real viewport, avoiding an unbounded automatic `frame_post_draw` wait on obscured macOS windows. Output declares changed pacing and forced draw. It remains a wall-clock diagnostic, not CPU evidence; A30 collection is unchanged.
