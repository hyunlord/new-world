### 파이프라인 검증 결과

명도는 감마 인코딩된 sRGB에서 Y′=(0.2126R+0.7152G+0.0722B)/255입니다. 주민의 불투명 픽셀 평균(외곽선 포함)과 절차적 지면 평균의 절대 차를 측정했습니다. 선형 광량이나 접근성 대비율과 같은 값이 아닙니다. 실제 불투명 픽셀 바로 밑 지면의 평균과 차이도 각 `readability.json`에 따로 기록했습니다. 지면색은 주민을 보기 전에 녹색 계열의 낮은 채도 순으로 결정하므로 결과에 맞춰 배경을 조절하지 않았습니다. 이 지면 한 종류의 통과가 모든 게임 지면 통과를 뜻하지 않습니다.

### 추천

**D3를 생산 방향 후보로 추천합니다.** 정해진 작은 크기에서 실제 주민 대비가 통과하고, 넓은 색면을 유지하는 편이 1인 개발과 다수 주민 화면에 적합합니다. 다만 현재 스프라이트를 그대로 게임에 넣는 추천은 아닙니다. 붉은 열매·주황 불꽃 전용 색 역할을 포함한 수작업 팔레트 확정, 네 열매 단계와 역할별 실루엣 보정 후 다시 검증해야 합니다.

### 확인된 제한사항

- 원본은 내장 image_gen으로 생성했습니다. 도구가 모델명을 노출하지 않아 요청된 gpt-image-2인지 독립 확인할 수 없습니다. 배경 투명 옵션은 사용하지 않았습니다.
- 원본 장면은 1672×941, 시트는 1254×1254입니다. 장면은 최근접 리사이즈·중앙 크롭으로 1920×1080, JPEG quality 88로 저장했습니다. 생성된 장면의 텍셀 크기는 균일하지 않으며 정확한 16픽셀 타일·64×64 지도·1×/4× 구현 증거가 아닙니다. D1/D2는 특히 배경이 조밀합니다. 정규화된 PNG만 네이티브 규격의 증거입니다.
- 생성된 장면에 동물·식량 종류 등 현재 시뮬레이션에 없는 장식이 들어갔습니다. 현재 게임 콘텐츠라고 주장하지 않습니다.
- JPEG 압축은 픽셀색을 바꿉니다. 팔레트 일치 검사는 PNG 스프라이트에만 적용했습니다. 무안티앨리어싱 HUD 원본은 PNG로 따로 보관했습니다.
- D1/D2 가독성 기준 미달, 모든 방향의 열매 단계 의미 손실은 남아 있습니다. 실패 수치를 숨기거나 통과 기준을 낮추지 않았습니다.
- 기준 Rust 테스트는 Godot가 `WorldSimNode`를 찾지 못해 `harness_p12_beta_a25_gdscript_parses_cleanly_in_godot_headless`에서 실패했습니다. `cargo clippy --workspace -- -D warnings`는 통과했습니다. 게임 코드 수정은 범위 밖이라 하지 않았습니다.
- Python 실행·단위 테스트·실제 시트 CLI·산출물 검증을 수행했습니다. 설치된 ruff/basedpyright가 없어 해당 검사 결과는 없습니다. 실제 게임 렌더링·대규모 주민 성능·애니메이션·기기 검증은 수행하지 않았습니다.

**생산 검사 통과로 바뀐 것은 아니다.** D2·D3 빈 덤불은 빨강 기준에 걸리는 2텍셀 때문에 열매 검사가 실패한다. 이는 실제 열매인지 갈색 줄기인지 구분하지 않는 색 기반 검사다. 세 방향 모두 보수적인 ΔE 검사에 실패했다. D1은 16개 전부 크기 한도를 초과한다. D2 일부 배우와 D3 아이는 축별 주기 차이로 비율 왜곡이 보인다.

ΔE는 단계3 불투명 텍셀 전체를 최종 외곽선 전 이미지와 비교한다. spill 제거로 사라진 텍셀도 투명 검정 RGB와 비교하므로, 의도한 키 제거까지 실패값에 포함하는 보수적 정의다. 개별 스프라이트 평균도 6 이하여야 통과한다. 피부 비율은 색 램프 대리 지표이며 옷을 피부로 셀 수 있다. 모든 최종 스프라이트는 팔레트 소속 100%, 이진 알파를 만족한다.

|D3|95%|95%|0.2759 / 0.2760|47.966 / 47.969|
|H|95%|95%|0.2819 / 0.2819|44.628 / 44.628|

보임 비율은 주민 제거 전후 전체 화면에서 해당 박스의 20% 이상이 명도 0.12 이상 변하는 기준이다. 목표는 4배 90%, 1배 75%. 명도·ΔE 평균은 y 정렬·다른 물체·HUD 가림을 반영한 해당 주민의 보이는 불투명 기여 텍셀만 사용하며, 박스 전체 평균도 JSON에 따로 보존한다. 명도는 감마 인코딩 sRGB Rec.709 가중합 /255다.

정수 최근접 확대는 픽셀 비율을 유지하므로 4배·1배 수치가 거의 같다. 이것은 사람이 같은 수준으로 알아본다는 뜻이 아니다. 특히 1배에서 직업·표정은 어렵고, D1은 큰 원본 크기 덕에 더 잘 보인다. 서로 겹친 주민 박스는 보임 비율에 타인의 변화도 포함할 수 있다. 개별 주민 지표와 박스 좌표는 각 방향 readability_v2.json에 있다.

- D1: 큰 실루엣과 세부가 눈에 잘 들어온다. 야간 외곽은 어두워지며, 개요의 우위에는 규격 초과 크기가 섞여 있다.
- D2: 작은 실루엣과 눌린 비율 때문에 수치상 100%와 달리 역할 식별은 약하다. 밤에는 외곽 구분이 더 어려워진다.
- D3: 단순한 수관과 인물 표현이 잘 맞고 열매·불·피부의 구분이 돌아왔다. 아이의 폭과 일부 크기는 수정이 필요하다.
- H: 차분한 지면 위 D3 배우가 분리된다. D1 수목·갈대의 큰 크기와 높은 세부 밀도가 배우와 충돌한다. 야간의 개선 우위는 입증되지 않았다.

### 점수표

5점 척도. 각 셀은 **1차 → 2차**. 측정 수치와 시각 검토를 함께 사용한 주관적 평가이며, 생산 준비는 현재 실패 항목을 반영한다.

|방향|4× 가독성|1× 가독성|통일성|석기시대|야간|200개 생산 준비|
|---|---:|---:|---:|---:|---:|---:|
|D1|3 → 4|2 → 4|4 → 4|4 → 4|4 → 3|3 → 1|
|D2|3 → 3|2 → 2|4 → 3|4 → 4|5 → 2|2 → 1|
|D3|4 → 4|3 → 3|4 → 4|4 → 4|4 → 3|3 → 2|

D1의 1배 4점에는 큰 네이티브 크기의 이점이 포함된다. 1차의 가독성 순위는 훼손된 변환 결과를 측정했으므로 이번 순위의 근거로 재사용하지 않았다.

### 추천

**D3를 우선 검토 후보, H를 지면 비교 후보로 유지한다.** 추천 이유는 복원 후 드러난 색 구분과 인물·수목 표현의 일관성이다. 1차의 낮은 실험값과 비교해 승자를 단정할 수는 없다. H는 분리감의 가능성을 보였으나 통일성과 생산 비용에서 D3보다 낫다는 증거는 부족하다. 최종 방향은 소유자가 선택하며, 생산·게임 설치는 시작하지 않았다.

### 확인된 제한사항

- 오프라인 합성 평가다. Godot 실행, 애니메이션, 실제 시뮬레이션, 장치 성능, 사람의 플레이 판단은 검증하지 않았다.
- 지정된 평균 경계 에너지 탐색은 일부 축에서 다른 주기/고조파를 선택한다. 합성5.9배 테스트 통과가 모든 생성 원본의 올바른 격자를 보장하지 않는다.
- 피부·열매 판정은 색상 대리 지표다. 물 강조색은 물 셀이 없어 실제 네이티브 색 중 기준색에 가장 가까운 색을 택했다.
- ±1도 의복 색상 변이는 낮은 채도의 하체 중앙 영역을 쓰는 휴리스틱이다. 피부와 옷을 확실히 분리하지 못하고, 중성색·반올림 때문에 변화가 없는 자산도 있다. 방향별 변경 텍셀 수를 JSON에 기록했다.
- 잔디·흙·물결의 국소 장식은 타일 경계를 피한다. 이어지는 강·1텍셀 강둑은 경계를 가로지르는 지형 예외다. 반복 숲과 각진 마당은 비교용 배치의 한계다.
- 20명 배치와 정적인 인구31 HUD는 각각 비교 장면과 1차 UI 증명용 수치이며 실행 중 게임 상태가 아니다.
- 재생성 대상도 크기를 줄이지 않고 장면에 사용했다. 이 화면은 생산 승인본이 아니다. 그림 비교 보드의 축소판보다 개별1920×1080 PNG를 원본 배율로 확인해야 한다.
