## 아트 방향 보고

검토용 아트 방향 패키지입니다. 게임 코드·런타임 에셋은 변경하지 않았으며 생산을 시작하지 않았습니다. [비교 보드](direction_compare.jpg), [아트 바이블](ART_BIBLE.md), [생성 기록](generation_ledger.json), [결정 기록](DECISIONS.md)을 함께 보십시오.

### 파이프라인 검증 결과

최종 48/48 스프라이트는 지정 크기, 팔레트 100%, 부분 알파 0, 위·좌우 경계 침범 0, 바닥 접촉을 통과했습니다. 선택된 원본 시트도 셀 경계 침범이 없습니다. 외곽선은 외부와 연결된 투명 영역에만 추가하여 내부 구멍을 보존합니다.

|방향|정규화 통과|팔레트 일치|최소 주민 명도 차|목표 ≥0.15|
|---|---:|---:|---:|---|
|D1|16/16|100%|0.008213|미달|
|D2|16/16|100%|0.002254|미달|
|D3|16/16|100%|0.214027|통과|

명도는 감마 인코딩된 sRGB에서 Y′=(0.2126R+0.7152G+0.0722B)/255입니다. 주민의 불투명 픽셀 평균(외곽선 포함)과 절차적 지면 평균의 절대 차를 측정했습니다. 선형 광량이나 접근성 대비율과 같은 값이 아닙니다. 실제 불투명 픽셀 바로 밑 지면의 평균과 차이도 각 `readability.json`에 따로 기록했습니다. 지면색은 주민을 보기 전에 녹색 계열의 낮은 채도 순으로 결정하므로 결과에 맞춰 배경을 조절하지 않았습니다. 이 지면 한 종류의 통과가 모든 게임 지면 통과를 뜻하지 않습니다.

셀 01→16 순서별 사용 색 수:

- D1: 15, 13, 16, 15, 13, 13, 12, 14, 12, 11, 10, 11, 16, 16, 17, 12.
- D2: 27, 26, 28, 21, 15, 16, 16, 17, 21, 14, 20, 18, 20, 20, 22, 14.
- D3: 15, 11, 9, 10, 11, 11, 10, 11, 6, 6, 7, 5, 13, 11, 12, 4.

원본 대비 D1은 바구니 내용물·얼굴·열매 빨강, D2는 나뭇잎의 미세 명암·가죽 질감·작은 도구, D3는 역할별 옷·바구니·열매 빨강을 잃었습니다. 세 방향 모두 3/2/1/0 단계의 즉시 판독은 충분하지 않습니다. 원본의 ‘full bush’에는 3개보다 많은 열매가 있어 생산 시 정확한 세 표시점으로 다시 그려야 합니다. 정규화의 기계적 통과와 콘텐츠 의미 보존은 별도입니다.

자세한 셀별 수치: [D1](D1/normalize_report.md), [D2](D2/normalize_report.md), [D3](D3/normalize_report.md). HUD 글자 대비율은 D1 7.00:1, D2 7.66:1, D3 6.04:1이며 한글 잘림·겹침은 발견하지 못했습니다. 손실 없는 `hud_proof.png`에서 이진 알파와 정수 확대를 검증했습니다.

### 추천

**D3를 생산 방향 후보로 추천합니다.** 정해진 작은 크기에서 실제 주민 대비가 통과하고, 넓은 색면을 유지하는 편이 1인 개발과 다수 주민 화면에 적합합니다. 다만 현재 스프라이트를 그대로 게임에 넣는 추천은 아닙니다. 붉은 열매·주황 불꽃 전용 색 역할을 포함한 수작업 팔레트 확정, 네 열매 단계와 역할별 실루엣 보정 후 다시 검증해야 합니다.

섞는다면 D1의 낮은 지면 채도와 D2의 ‘불 주변은 따뜻하게, 멀리는 차갑게’라는 조명 관계를 가져오되, D3의 큰 색면과 적은 질감은 유지하는 편이 좋습니다. 팔레트 세 개를 합치는 방식은 피하십시오. 최종 방향은 소유자가 선택합니다.

### 사용량

생성 도구 호출 **15회**: 반환 성공 15, 도구 실패 0. 품질 검사에서 초기 시트 2장을 탈락시켜 재생성했습니다. 시험 1회 + D1 4회 + D2 5회 + D3 5회입니다. 총 30회 및 방향별 9회 한도를 모두 지켰습니다. 추가 생성은 하지 않습니다. 정확한 프롬프트·실제 크기·참조·파일 시각은 생성 기록과 원본 JSON에 있습니다.

클론 생성 기준 시작 2026-10-10T08:04:58.882308+00:00, 보고서 기록 2026-10-10T08:24:05.564415+00:00; 경과 19.1분. 최종 게이트·푸시 시간은 최종 검증 기록에서 추가 확인합니다.

### 확인된 제한사항

- 원본은 내장 image_gen으로 생성했습니다. 도구가 모델명을 노출하지 않아 요청된 gpt-image-2인지 독립 확인할 수 없습니다. 배경 투명 옵션은 사용하지 않았습니다.
- 원본 장면은 1672×941, 시트는 1254×1254입니다. 장면은 최근접 리사이즈·중앙 크롭으로 1920×1080, JPEG quality 88로 저장했습니다. 생성된 장면의 텍셀 크기는 균일하지 않으며 정확한 16픽셀 타일·64×64 지도·1×/4× 구현 증거가 아닙니다. D1/D2는 특히 배경이 조밀합니다. 정규화된 PNG만 네이티브 규격의 증거입니다.
- 생성된 장면에 동물·식량 종류 등 현재 시뮬레이션에 없는 장식이 들어갔습니다. 현재 게임 콘텐츠라고 주장하지 않습니다.
- JPEG 압축은 픽셀색을 바꿉니다. 팔레트 일치 검사는 PNG 스프라이트에만 적용했습니다. 무안티앨리어싱 HUD 원본은 PNG로 따로 보관했습니다.
- D1/D2 가독성 기준 미달, 모든 방향의 열매 단계 의미 손실은 남아 있습니다. 실패 수치를 숨기거나 통과 기준을 낮추지 않았습니다.
- 기준 Rust 테스트는 Godot가 `WorldSimNode`를 찾지 못해 `harness_p12_beta_a25_gdscript_parses_cleanly_in_godot_headless`에서 실패했습니다. `cargo clippy --workspace -- -D warnings`는 통과했습니다. 게임 코드 수정은 범위 밖이라 하지 않았습니다.
- Python 실행·단위 테스트·실제 시트 CLI·산출물 검증을 수행했습니다. 설치된 ruff/basedpyright가 없어 해당 검사 결과는 없습니다. 실제 게임 렌더링·대규모 주민 성능·애니메이션·기기 검증은 수행하지 않았습니다.
