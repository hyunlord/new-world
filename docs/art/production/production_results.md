## 제한사항

기존 D3 방향 자산 16개는 생산 256개와 별도이다: {'provisional': 9, 'accepted': 7}. provisional 상태를 생성 수용으로 승격하지 않았다.
생산/기존 항목 156개에 제한사항이 기록되어 있다. 수용된 같은 방향 idle이 없으면 D3 정면을 사용하므로 방향 충실도와 체형 다양성이 부족할 수 있다. 절차적 대체는 생성 수용을 의미하지 않는다.
변환기 요구 6.1은 완전 충족되지 않았다. raw JPEG 색 복원과 강한 2배 주기 반례는 converter_literal_audit.md에 실패로 공개했다. 일반 단위 테스트 통과와 구분한다.
최종 수면 수정: V_a3_13/V_b3_13은 수용된 V_b1_16의 북향 걷기 프레임을 정확히 90도 회전하여 28×14 모피 캔버스에 놓았다. 원본 불투명 texel은 보존했으나 성인 A의 체형·원래 S idle 방향과 다르다. 앉기/웅크림 7개는 다리 두 행을 몸통 바로 아래에 연결했다. 상세 ID는 rest_fallback_refresh.json.
