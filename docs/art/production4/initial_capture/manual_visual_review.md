# Art Pass 4 수동 정지화면 검토

검토 범위: `GOAL.md` §12와 아래 9개 이미지의 직접 시각 확인만 사용했다. 이전 판정, 구현 코드, 실행 로그는 읽지 않았다. 게임 실행·조작·동영상 검증은 수행하지 않았다. 따라서 이 문서는 전체 인게임 승인이나 성능 승인으로 사용할 수 없다.

## 판정

**부분 개선 확인, 전체 시각 수용은 보류.** 자연스러운 피부·가죽 의복의 색 분리는 명확히 좋아졌다. 낮의 빈 화덕, 밤의 불과 국소 밝기, 장작 HUD도 읽힌다. 그러나 24일차 캠프는 주민과 천막이 심하게 겹쳐 개별 주민과 화덕 주변 공간을 읽기 어렵다. 화면 여러 곳의 바구니도 사람 몸과 분리되어 보여, 실제 운반 동작을 그림만으로 명료하게 전달한다는 조건을 충족했다고 판단할 수 없다.

## GOAL §12 조건별 수용 범위

1. **피부·옷 색: 시각적으로 개선 확인.** 검토한 낮 화면에서 올리브 피부나 분홍 얼룩은 두드러지지 않는다. 모든 변형·모든 프레임 및 원본 의복 색 보존은 미검증이다.
2. **머리색: 정적 변형만 확인.** 흰색·회색 머리는 보이지만 노인에게만 적용됐는지, 움직일 때 안정적인지는 미검증이다.
3. **운반·걷기·짓기·음수: 수용 보류.** 분리된 바구니가 여전히 보이고, 실제 손 운반·아이 보행·돌망치·음수 동작은 제공된 화면만으로 명료하게 확인되지 않는다. 특정 코드 경로나 아이콘 구현 방식의 문제라고 단정하지 않는다.
4. **화덕 주변 자리·클릭: 시각 조건 미충족, 클릭 미검증.** 특히 24일차 캠프의 실루엣 겹침이 강하다. 클릭 대상 일치 여부는 실제 조작이 필요하다.
5. **아침·저녁 식사: 미검증.** 주요 개별 캡처 시간은 12시, 15시, 23시로 지정 식사 시간대를 보여주지 않는다. 앉은 그림만으로 식사라고 판정하지 않는다.
6. **나무 수집·어깨 운반·고갈·재생: 미검증.** 가지·장작 형태는 보이나 수집 전후와 이동 과정의 연속 증거가 없다.
7. **불과 장작: 낮/밤 외형만 부분 확인.** 낮의 빈 돌 둘레와 밤의 불·주변 밝기는 확인된다. 정확한 18시~07시 제한, 무장작 소등, 계절별 장작더미 증감은 미검증이다.
8. **자원 표시: HUD·저장소 라벨 확인.** 주민 정보창이 없어 땔감 목표·운반 수는 미검증이다.
9. **계절: 봄 d32 표기 확인.** 동일 주민의 색 불변과 환경에만 계절 변조가 적용되는지는 정지 스트립으로 확정할 수 없다.
10. **오류·성능: 미검증.** 정지화면은 SCRIPT ERROR 부재나 Art Pass 3 대비 프레임 시간을 입증하지 않는다.

다음 수용 검증은 혼잡한 24일차 캠프의 개별 주민 식별·클릭, 실제 운반 이동과 아이 보행, 지정 시간 식사, 나무 수집 전후·재생, 장작 소진 시 소등을 연속 실행 증거로 확인해야 한다. 이 문서 작성 외 파일은 변경하지 않았다.
