1. **피부·가죽색:** 검토한 화면의 주요 주민은 따뜻한 갈색·주황갈색 피부와 밝은 가죽 의복으로 읽힌다. 눈에 띄는 분홍 피부 얼룩은 없다. 모든 변형·원본 색 완전 보존은 미검증이다.
2. **머리:** 검정·갈색·회색·흰색 차이는 보인다. 회색·흰색이 노인에게만 적용되는지와 이동 중 깜빡임은 미검증이다.
3. **운반·걷기·짓기·음수:** 몸과 분리되어 보이는 바구니 때문에 운반 가독성은 수용 보류다. 바닥 자원인지 머리 위 표시인지 구현 원인을 단정하지 않는다. 실제 운반 프레임 이동, 아이 보행, 돌망치 짓기, 물 마시기의 연속 동작은 미검증이다.
4. **캠프 자리·클릭:** 18일차·24일차의 강한 겹침 때문에 화면상 자리 배치 조건은 미충족이다. 클릭 대상 일치는 실제 조작을 하지 않아 미검증이다.
