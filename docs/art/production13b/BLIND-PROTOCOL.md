# Prospective screen-reading protocol

Recorded before any Pass13b captures or reader answers.

## Activity stage B

Use final current game_v26 Z4 captures: live default seed day30 at10:00 and15:00, seed20261018 day60 at10:00; only inherited Pass11 supplement rules may add candidates. Preserve raw captures and sidecars. Before any crop, freeze exclusions: reject a holder when more than50% of either its body rect or icon rect is covered by later-drawn bodies/icons. Crop union(body,icon), grow8 screen px on each edge, square around its centre; never rescale. Hidden-icon holders use head_icon_position geometry, as inherited protocol specifies.

Select two eligible holders per each of seven activities using the inherited deterministic selection rules. Preserve insufficient kinds rather than fabricate substitutes. Record all selected source IDs and file hashes in a withheld answer key.

A fresh reader with no parent conversation first sees the labelled legend sheet. After confirming it has seen the legend, give shuffled crops and the seven activity names, with no keys. Freeze verbatim answers with timestamp and hashes before revealing keys or computing scores. Pass requires at least12/14 and no activity0/2. Keep failures. Do not redesign after seeing answers and relabel them as the original run.

Without-legend reading uses a separate fresh reader with crops and seven names only; freeze before scoring. Report without a pass bar. Village summary uses inherited six-pair protocol after activity answers freeze, only if six eligible pairs exist; otherwise report count and NOT_RUN.

## Fact reading

Use final Life-size EN/KO screenshots for the inherited living/dead-parent, chronicle, selected crowd, available departure causes, porter and available quarreller subjects. Add reconciliation if present. A fresh reader sees screenshots only and writes learned facts, names and explicitly marked inferences. Freeze answers before exposing bridge/chronicle data.

Score every non-name statement against visible content and independent data. Every scored non-name statement must be correct. Separately report name count/errors and confusion pairs. Claims not verifiable from the screen are recorded as unverified and excluded from scoring; do not turn an incorrect verifiable claim into an inference retrospectively. Automated glyph distinctness and reader facts are independent evidence.
