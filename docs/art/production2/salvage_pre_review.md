## Selection and provenance

Character groups stay within a single body, sheet, attempt, view and activity. Frame-local guards are applied first. Missing frames are derived only from passing members of that group; equal cycle phases can be copied (for example frame4 from2), otherwise existing procedural animation rules are used. All derived output is guarded again, then the completed group is checked. Ready groups rank by number of original passing frames, then their mean ΔE, then attempt number. Derived count never improves an attempt's score. Original failed records remain intact. Derived fidelity is explicitly inherited from its source rather than presented as a new raw comparison.

Object choices first use warning count, ΔE and attempt order. The ledger keeps those initial independent choices. All available four-stage berry combinations are checked for strict semantic order, and valid sets rank by total warnings, total ΔE and attempt tuple. Basket alternatives must satisfy the selected bushes. The selected set is checked again after exclusions; final cross guards pass. No passing basket alternative satisfied the chosen bushes in this run, so the two basket slots remain empty; the initial failure is retained separately.

Only two old manual geometry observations survive as guards: `V_a2_attempt_1.json` observed five rows and `V_b2_attempt_1.json` observed six rows, both against the requested four. Their `manual_grid_review.valid=false` yields `invalid_grid_layout` on 32 cells. Old size, ΔE≤6 and missing-idle rejections are not inherited.

References are adult_a `V_a1_01@1`, adult_b `V_b1_01@2`, child `V_c1_01@1`. Every candidate exposes raw crop, quantized unfitted native, fitted native/sprite when available, factor, grid evidence, metrics, local/group/cross guards and explicit lineage. Images live under ignored `.harness/evidence/art-production2/candidates/` (about67MB), not the documentation budget. Raw originals are unchanged. Initial pre-alternative ledger is preserved locally as `.harness/evidence/art-production2/candidates_initial.json`.
