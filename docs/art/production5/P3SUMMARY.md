## 설치와 제한

- a/b 승인 후보를 기존 승인 후보와 함께 세트 단위로 다시 탐색했다. 새로 설치된 것은 성인 두 체형의 N 방향 `carry_wood` 두 그룹, 8프레임(실제 그림 5, 같은 위상 복사 3)이다. `masks/harvest/`가 탐색·애니메이션·설치 근거다.
- c 승인 24개가 속한 현재 애니메이션 13그룹 전체를 독립 리뷰했다. 9그룹 승인, 4그룹(E drink, E eat, S drink, S idle)은 `cycle_pop` 거절이다. 모든 그룹의 원본 시트·시도 세트는 같음을 확인했다.
- c 마스크 15개를 동결하고 표준 설치 경로로 적용했다. 9개는 미설치: 애니메이션 거절 5개, Part 1에서 이미 RGBA가 바뀐 E carry 4개다. 실패한 그림과 상태를 승인으로 바꾸지 않았다.
- 적용한 15개 중 14개는 감사 당시와 RGBA가 같아 이전 `accepted`로 복구했고, V_b3_12는 감사 이후 대체된 RGBA이므로 현재 상태를 유지했다. 적용 직전/직후 drawable 상태: accepted 197→211, fallback 47→33, derived 13→13, procedural 33→33, 합계 290.
- 감사 원본은 손실 없는 6배 보드와 당시 마스크 알파로 복원하여 비교했다. 전체 c29개 중 27개가 같은 RGBA이고 V_b3_03/V_b3_12는 달랐다. `masks/audit_binding.json`이 실제 감사 원본 판정이다. 최초 후보의 `audited_rgba_sha256` 필드는 당시 작업 시작 스냅샷 해시였으므로 상태 복구에는 사용하지 않았다.
- `HairRegistry`와 region 재구축은 P4와 P5 레지스트리를 읽고 같은 body/activity/RGBA 키에 P5를 우선한다. 굽힌 gather_wood의 frame 0과 key hair만 너비 예외이며 asleep/lying 제외는 유지한다.
- 첫 회수 보드의 원시 셀은 최상위 이미지 목록에 없어 누락 표시되었다. 조상 레코드에서 원본을 찾아 76개의 보충 raw/unfitted 보드를 제공했다. 이전 판정은 수정하지 않았다. 최종 미승인 45개의 결함은 해결된 것으로 보고하지 않는다.
