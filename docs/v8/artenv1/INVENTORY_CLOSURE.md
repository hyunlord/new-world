## 실제 source와 그리기의 경계

같은 native save의 terrain/person identity/벽·site·floor·bed·ford/item kind·count/zone/live animal은 보조 bridge layer로 읽고 그린다. **원본 bridge capture에 필드가 있다는 것과 그림이 있다는 것은 다르다.** designation, resource-node 잔량, item quality/covered, delivery/work progress, dug 경계, room role/override/roof, hunt-zone/marked/huntable, routine별 동작은 일부 또는 전부 raw에 보존됐어도 해당 표시가 없으며 아래 보류/부분 행으로 남긴다.

M00–05/M07–08, R00–04, B15/E17, E06–08은 예정했던 code overlay 자체가 미구현이다. E00 smoke는 원본만 있고 lit/fade 소비자가 없다. B16/E13은 site wash와 finished 구별까지만 구현했고 배송/작업 수치 표시가 없다. 이런 행을 다른 activity marker나 wall 그림으로 덮어 커버됐다고 세지 않는다.

Native 완료 Storehouse role은0이다. 실제 zone2 stockpile과 미완성 벽 둘레가 존재하며 선언 completed storehouse와 별개의 before target이다. 자세한 좌표·source 증거는 [BASELINE.md](BASELINE.md)와 [baseline manifest](reference/baseline_manifest.json)를 따른다.
