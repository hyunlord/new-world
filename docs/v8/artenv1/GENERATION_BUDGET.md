# ENV1 생성 예산 통합 기록

**호출 수·시도 상한 검증 PASS / 출처 기록 완전성 PARTIAL.** 동결된 lane 원장을 통합한 실제 합계는 **135/260회**다. 도구 출력 생성 성공 134회와 생성 전 거절 1회를 모두 센다. 성공은 출력 파일이 만들어졌다는 뜻이며 스타일·구조·의미 수락을 뜻하지 않는다. 새 생성이나 자산 수정 없이 원장만 통합했다.

| Lane | 자산 원본 출력 | 이미지 모델 점수표 출력 | 생성 전 거절 | 전체 시도 |
|---|---:|---:|---:|---:|
| 건축·지형·작업대·눈 | 47 | 9 | 0 | 56 |
| 아이템 | 23 | 3 | 1 | 27 |
| 동물 | 4 | 5 | 0 | 9 |
| 초상 | 36 | 7 | 0 | 43 |
| **전체** | **110** | **24** | **1** | **135** |

전역 한도 260에서 남은 산술 차이는 **125회**다. 이 차이는 추가 호출 승인이나 새 배정이 아니다. 이번 통합이 부여하는 추가 호출 권한은 **0회**다. 명시적으로 보존된 별도 lane 배정은 초상 78회뿐이며, 다른 lane의 최초 배정 숫자는 `NOT_RECORDED`로 남겼다. 위 표의 소비량을 최초 배정으로 재해석하지 않는다. 전역 한도와 일반 자산당 3회는 `ENV1_GOAL.md`, 초상당 2회 및 이름 변경으로 예산을 초기화하지 않는 규칙은 `ENV1_DECISIONS.md`, 초상 lane 78회는 `PORTRAITS.md`에 근거한다.

## 한도와 중복 검사

- 일반 자산 원본은 동일 ID당 최대 3회다. 재포장·파생 타일·기존 파일 재사용을 새 자산으로 세어 예산을 초기화하지 않았다.
- 늑대 시트는 정확히 try1·try2·try3, 사슴은 try1이다. 시트를 자른 프레임 20개를 별도 생성 호출로 세지 않는다.
- 초상은 실제 채택된 34룩만 대상으로 한다. `adult_F_fur_cloak_long_tied`, `adult_F_loincloth_bun` 각 2회, 나머지 32룩 각 1회다.
- `snow_overlay`는 정확히 1회다. 추가 눈 생성 권한은 없다.
- 성공 출력의 도구 원본 경로 134개와 이벤트 ID 135개가 각각 유일하다. 한 scorecard가 여러 자산을 채점해도 호출은 1회다. 아이템 card1의 실패와 성공 재시도는 서로 다른 두 이벤트다.
- 기존 자산 재사용, crop/resize, 합성 보드, 코드 tint, 이미지 생성 도구를 호출하지 않은 독립 판독은 이 이미지 생성 원장에서 0회다.

모든 자산 ID의 시도 번호·소비량·상한은 [generation_ledger.json](generation_ledger.json)의 `asset_budgets`에 있다. 실제 도구 출력 UUID를 `event_id`의 안정적인 식별자로 사용한다. 출력이 없는 실패 1회는 lane·scorecard ID·보존된 실패 시각을 조합한 명시적 ID로 남긴다.

## 원장 출처와 검증

원장은 다음 권위 파일의 경로·SHA-256·JSON pointer로 각 호출의 전체 프롬프트와 판정 기록을 연결한다. 프롬프트 본문을 또 복사해 별도 버전으로 만들지 않는다. 각 이벤트에는 실제 원본 파일과 복사된 raw의 SHA-256, 기록된 참조 파일과 해시, 원장 내 호출 인덱스가 있다.

- 건축: 원래 `built_generation_ledger.json`의 `asset_generations` 47개와 `model_reviews` 8개를 그대로 유지하고, `built_reuse_recheck.json`의 추가 점수표 1개를 별도 출처로 연결했다.
- 아이템: `items_manifest.json`의 실제 `attempts` 23개, `items_model_reviews.json`의 점수표 3개 및 `failed_call` 1개. 기존 자산 9개와 파생 상태는 원본 생성으로 중복 계수하지 않았다.
- 동물: `animal_attempts.json`의 기록 9개. 외부 prompt 파일과 raw를 각각 byte hash로 확인했다.
- 초상: `portrait_manifest.json`의 시도 36개 및 scorecard 7개, 외부 `portraits/ledger.json`과 `portraits/score_ledger.json`의 도구 원본 경로·프롬프트.

134개 성공 호출마다 tool 원본과 raw 복사본의 SHA-256이 같음을 확인했다. 각 lane에 기록된 참조 해시 연결 398개도 실제 파일과 대조했다. 통합 전후 8개 원천 JSON의 해시가 같아 자산·manifest·lane 원장을 변경하지 않았음을 확인했다. `generation_ledger.json`은 1.5 MB 미만이다.

## 추가 이벤트 135

현재 재사용 중인 `hut`, `knapping_spot`, `woodworking_bench`의 실제 모델 점수표 한 장을 원장 끝에 추가했다. 기록된 예약 번호는 전역 135·건축 lane 56이며, 예약/시작/수신 시각과 전체 프롬프트·입력 다섯 개·tool 원본·raw·미리보기 해시가 모두 보존돼 있다. 기존 이벤트 1–134, 원래 55회 건축 원장, 자산 시도 수, 이전 PARTIAL 결손은 변경하지 않았다. 새 점수표는 모델 결과만 추가하며 기존 수락을 덮어쓰거나 runtime 수치 실패를 통과로 바꾸지 않는다.

- 권위 기록: [built_reuse_recheck.json](built_reuse_recheck.json), [해석과 한계](built_reuse_recheck.md).
- 실제 점수표: `art/style05/env1/built/reuse_current_scorecard.png`, 1,195,485 bytes, SHA-256 `1867003584b60478d16a6322cf20d830f372bd148df5765f0da3bcfd3a057543`.
- 도구 원본/raw SHA-256: `b21e2352dc33efeb3027a8ce7bf9e108809f1b549d05e9b9004c37f6ab585294`.
- 이전 134개 이벤트는 필드별 동일성을, 전체 134개 출력 쌍과 398개 기록된 참조는 실제 파일 해시를 다시 확인했다.

## 보존한 기록 결손

1. **호출 시간 52회 미기록:** 동물 9회와 초상 43회의 권위 원장에는 호출 시각이 없다. `started_at`·`completed_at`을 `null`, 상태를 `NOT_RECORDED`로 남겼다. 파일 생성/수정 시각이나 이미지 UUID를 호출 시각으로 대체하지 않았다. 건축·아이템 성공 82회에는 보존된 시작/종료 경계 시각이 있고, 실패 1회에는 실패 기록 시각만 있다. 내부 모델 스케줄 시각은 공개되지 않았다.
2. **아이템 실패 요청 본문·참조 결손:** card1의 실패 기록은 참조 경로 5개 상한을 초과했다는 이유와 시각을 담고 있다. 같은 부모 객체의 현재 프롬프트와 참조 5개는 성공한 재시도용이다. 실패한 원래 요청의 정확한 본문·참조 목록을 그 값으로 덮어쓰지 않았으며 `NOT_RECORDED`로 표시했다. card1 성공의 `started_at`도 실패와 공유하는 준비 경계이며 정확한 재시도 시작 시각으로 해석하지 않는다.
3. **동물 모델 후보 attachment 결손 5회:** 실제 모델 심사 프롬프트는 세 번째 후보 그림을 언급하지만 `animal_attempts.json`의 참조 목록에는 locked anchor 두 개만 보존돼 있다. 기록된 두 anchor의 해시는 검증했으며, 누락된 후보 attachment의 경로·해시는 추정하지 않았다. 각 이벤트를 `PARTIAL_ANCHORS_ONLY`로 표시했다.
4. **전역 사전 예약 원장 증명 없음:** 이번 파일은 완료 후 통합 기록이다. `root_call_index`는 lane/원천 순서의 결정적인 통합 인덱스이며 실제 전역 호출 시간순을 뜻하지 않는다. 52회 시각 결손이 있는 상태에서 계획의 “호출 전 전역 행 예약”이 모두 수행됐다고 주장하지 않는다.

이 결손들은 호출 합계·출력 동일성·시도 상한 검증을 지우지 않지만 완전한 사전 호출 provenance PASS도 성립시키지 않는다. calibration·판독·오너 승인 상태는 각 lane의 기존 실패·후보 상태를 그대로 따른다.
