## 5. Population behavior freeze and required tests (P)

Atomic whole-wave admission. Capacity uses current all-Agent population, including children, plus full wave size <= configured population_cap. Check on explicit acceptance AND immediately before actual arrival-time joining. Early acceptance does not reserve capacity. Failed explicit answer has no world/ledger/attitude/spawn mutation. If a previous Accepted answer cannot fit on arrival, clear answer and enter/remain Waiting at its normal arrival deadline; no automatic decline/attitude penalty. Explicit user decline/timeout retains ordinary behavior. Exact-fit succeeds; zero-cap and already-over-cap reject. Preserve preassigned IDs and normal successful joining.

Precommit deterministic test matrix: (1) population38+wave2 fits40; (2)39+2 rejects; (3)40+1 rejects; (4)35adults+4children+2 rejects; (5) early38+2 accepted, one birth before arrival => no join, Waiting/no answer; (6) early answer then death opens capacity => valid eventual join; (7) two waves compete and command/arrival ordering admits only the fitting whole wave; (8) repeated accepted command produces no duplicate agents/items; (9) save/load between early answer and arrival rechecks capacity; (10) no cap failure writes ledger, membership, knowledge, apparel or attitude. Count capped attempts once per command/arrival transition, not once per tick. P is not a hard world-population cap on births: natural population can exceed40 through births; report migrant-caused over-cap admissions separately from all-population maxima.
