# ART-PROD1 결정 기록

- D01: 목표 문서의 명시 범위가 일반 브랜치/문서 갱신 규칙보다 우선한다. `v8/art-prod1`에서 `art/**`, `docs/v8/artprod1/**`만 변경·커밋한다. 게임 코드, merge, 다른 브랜치 이동은 없다. 기존 `.ignore`, `.gitignore`, `.omo/`, `docs/art/`는 보존한다.
- D02: Part 0 계측기 수정·검증·TRIAL5 재집계 이전에 생성하지 않는다. 36룩 각각 최대 3회, 총 108회; 최초 완전 통과에서 중지한다. 리뷰 후에는 미독해 룩만 남은 한도 안에서 1회 교정 라운드를 허용한다.
- D03: 역사 원본을 확인하니 Part 0 I-1은 1024×1536 단일 idle 인물이며 5자세 시트가 아니다 (`docs/v8/arttrial5/GENERATION_LOG.json`). 존재하지 않는 다섯 패널을 만들거나 복제하여 교정 통과로 계산하지 않는다. 원본 I-1을 양성 대조군으로 검사하고 실제 I-1 룩의 최초 생산 시트(adult_M_hide_wrap_short/S/try1)를 사전 지정한 별도 패널 대조군으로 쓴다. 불일치는 결과에 명시한다.
- D04: standing height는 idle의 인체 높이로 측정한다. 같은 시트 전 자세는 S idle에서 구한 단일 배율을 사용하며, 도끼·통나무를 포함한 work/carry 전체 높이를 56px로 강제하지 않는다. sleep 폭 48–60px는 별도 기준이다.
- D05: 전체 시트 judge는 역사/legacy 측정으로 보존하고 PROD1 수락에는 원본 해상도 패널의 alpha crop + 8% padding 판정만 쓴다. person calibration과 모든 임계값은 변경하지 않는다.
- D06: 사전 지정 교정 결과 I-1 원본 1/1 통과, 동일 룩 최초 실제 5자세 시트 4/5 통과(work_a stroke_q90 실패)다. judge v2는 내부에서 불투명 전경을 재크롭하므로 외부 padding을 튜닝해 통과를 만들지 않는다. 목표의 존재하지 않는 Part0 5패널 교정 조건은 NOT_VERIFIABLE로 남긴다. 입력 단위·불변 임계값·원본 해상도·교정 양성 대조군 검증을 완료한 후 생산을 진행하며 이 제약을 최종 보고서에 보존한다.
- D07: 수면 방향은 alpha≥128 인체 경계로 판단한다. alpha>0의 희미한 꼬리 때문에 이미 가로인 인물이 세로로 회전하던 오류를 실제 TRIAL5 재집계로 발견했고, 실패→통과 회귀 테스트로 수정했다. 회전은 전체 RGBA에 적용하여 faint pixel도 보존한다. 오류가 있는 최초 재집계는 폐기하지 않고 진단 기록으로 남긴다.
- D08: dust는 TRIAL5 소유권 규칙(원본 시트 면적 0.01% 미만 연결요소를 최근접 인물에 통째로 배정)을 유지한다. 이를 이유로 보이는 픽셀을 삭제하거나 최종 연결성 실패를 숨기지 않는다. 역사 처리기의 기본 정규화는 PROD1로 바뀌므로 TRIAL5 재현은 고정 커밋으로 해야 한다.
- D09: 재집계 72개는 모든 룩×방향의 생산 2차 시도 코호트다. 실제 TRIAL5 리뷰 라운드1 선택에는 동결된 S try1도 포함되므로 그 리뷰 표본과 동일하다고 표시하지 않는다.
- D10: 생성 초반 허리천 프롬프트가 의상 설명에 성인남/성인여/아동 대안을 모두 나열해 참조 I-1의 남성·가죽 형태로 편향되는 사례를 관찰했다. 이후 호출은 해당 룩의 의상만 명시한다. 이전 호출·거절·한도는 유지하고 리셋하지 않는다. 최초 기계적 통과 자산은 속성 오독 가능성을 기록한 채 블라인드 리뷰에 넘긴다.
- D11: 독립 감사에서 `check_set`이 MANIFEST 부재를 허용하는 결함을 발견했다. 누락 회귀 테스트의 실패를 먼저 확인하고 필수 MANIFEST 부재를 실패하도록 수정했다. 새 생성물은 이미 MANIFEST를 게시하고 있으므로 자산 변경은 없다.
