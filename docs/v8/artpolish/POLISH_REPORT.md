## 벽 윗면과 판 굴

권위 설정은 [wall_params.json](../../../art/compositor/wall_params.json)이다.
기본 `dark`, 1× box **9px**(반지름 4px), HSV value **×0.45**, saturation
**×0.40**. 비벽 타일과 닿는 경계는 **2px**, `#141210`, **80% alpha**다.
남쪽 면이 매달린 경계에만 **1px**, 잉크 전 cap value **+0.08**을 적용한다.
돌·나무 cap은 공통 strip의 무늬·명도·채도를 공유하고 팔레트의 색상 H만
다르다. 끝 조각은 실제 면의 끝에만 붙이고 cap·안쪽 코너에는 붙이지 않는다.

미굴착 언덕의 남쪽이 통행 가능한 굴착 타일이면 **언덕 쪽에서만** 바위 면을
그린다. 북쪽이 언덕인 굴착 타일에는 중복 면을 얹지 않는다. 굴착 바닥은
`floor_dug_rock`이고 **12px** 혼합은 다른 지면에만 적용한다. 언덕·벽 경계는
혼합하지 않는다. 입력 순서가 바뀌어도 굴착 바닥이 과거 언덕 표시보다 우선한다.

합성기 테스트 **76/76**, 독립 코드·시각 검토 통과. 보드 7개/17패널의

## 늑대·사슴

실루엣 설계는 생성 전에 [ITEMS.md](../../../art/style05/ITEMS.md)에 기록했다.
최초에는 명시된 13종을 재생성하고 다른 9개 이미지를 유지했다. 유지 대상 창의 기존
수치 스타일 실패, 베리 바구니의 기존 판독 실패도 숨기지 않는다.

| 라운드 | 리뷰어 | 32px 정확 종류 | 64px 정확 종류 | 필수 혼동 쌍 |
|---|---|---:|---:|---|

| 0 | B | 11/22 | 15/22 | 5묶음 모두 실패 |
| 1 | 새 A | 9/22 | 11/22 | 4묶음 실패 |
| 1 | 새 B | 9/22 | 12/22 | 4묶음 실패 |

기준은 32px 각각 17/22 및 필수 혼동 쌍 모두 충족, 64px 각각 20/22다.
의복 대분류 판독을 정확 종류 점수에 더하지 않는다. 라운드 0에서 망토는
그루터기, wrap은 주머니/묶음, 회색 raw pot은 돌 그릇, 연마 도끼는 일반
도끼, 점토는 접힌 가죽으로 읽혔다. 작은 통나무도 장작으로 오독되었다.
정확 이름·해석·오답은 [blind_items_round0.json](blind_items_round0.json)에 남겼다.

목표의 실패 후 재생성 규칙에 따라 오독 14종과 수치만 실패한 중간·큰
통나무를 합친 **16종**을 한 번 수정했다. 최초 유지 대상이었던 작은 통나무,
돌도끼, 베리 바구니도 실제 새 시험 실패에 따라 이 라운드에 포함했다(D6).
최종 선택은 이번 수정본 16개와 기존 유지본 6개다. 원래 목록의 13종은 모두
수정 라운드에 포함되며, 처음 보존했던 3종도 새 실패 근거로 교체되었다.
최종 수치 스타일 게이트는 **11/22 PASS, 11/22 FAIL**이다. 새 16개 중 6개,
유지 6개 중 5개가 통과했다. 이 실패는 D1의 비게이팅 예외 대상이 아니다.
새 16개 모델 스타일 점수표는 모두 각 항목 4 이상이지만 수치 실패를 상쇄하지
않는다. 마지막 판독은 새 리뷰어가 32px 답변을 저장한 뒤 64px를 열었으며,
작은 크기의 답변을 수정하지 않았다. 마지막에도 연마 도끼는 hoe/cleaver,
점토는 steak, flint는 ore, wrap은 animal hide로 읽히는 혼동이 남았다.

| 32px 필수 쌍 | 최종 A | 최종 B | 두 명 모두 충족 |
|---|---|---|---|
| 모든 log / firewood | FAIL | PASS | FAIL |
| stone / ground axe | FAIL | FAIL | FAIL |
| hide / cured hide | PASS | FAIL | FAIL |
| raw / fired pot | FAIL | FAIL | FAIL |
| wrap / cloak를 의복으로 | FAIL | FAIL | FAIL |

`basket`만 답한 것은 berries를 명시하지 않았으므로 정확 종류 오답이다.
설명란의 berries로 첫 이름을 보완하지 않았다. 독립 검토에서 이 의미 해석을
재확인했고, 인쇄 ID 오타는 원래 판독자가 ID만 별도 정정했다. 원시 답변은
그대로 남았다. [최종 판독·매핑](blind_items_round1.json),
[아이템 상세 기록](ITEMS.md)을 보존하며 추가 생성·추가 판독은 하지 않았다.

창은 판독은 되었지만 기존 스타일 수치 실패를 유지한다. 전체 실루엣 길이를
자루의 상한으로 잡아도 최종 돌도끼 대비 **1.170×**, 연마 도끼 대비
**1.282×**로 요구 **2×**에 못 미친다. 초기 비율 1.440×·1.211×도 보존했다.
해당 측정은 [items_length_check.json](items_length_check.json)에 있으며,
판독에 성공했다는 이유로 길이 조건을 통과 처리하지 않는다.

M-ART2에서는 **hover label과 inspector가 항상 아이템 이름을 표시**해야 한다.
이 판독 기준은 colony를 흘끗 볼 때의 구별 가능성을 확인하는 조건이다.

- `art/compositor/`: cap 파라미터·렌더 경계·합성 보드와 행동 테스트.
- `art/pipeline_polish/`: 원본 보존·정규화·블라인드 패킷 및 독립 채점.

- `art/style05/ITEMS.md`, `art/boards/`, `docs/v8/artpolish/`: 설계·보드·검증 기록.
- cap에서 재료별 다른 무늬와 코너 조각을 제거하고 기존 합성·분리·judge 함수를
  재사용했다. 게임 코드·전역 문서·의존성을 변경하지 않았으며 merge하지 않았다.
- 구조·해시·시험 통과는 사람의 시각 채택, 실제 게임 가독성 또는 FPS 증거가 아니다.
  블라인드 판독자는 독립 모델 에이전트이며 사람 대상 실험이 아니다.
- 최종 통합 타입 검사에는 오류 0개와 경고 14개가 남아 **NOT_GREEN**이다
  (합성기 10, 동물 3, 아이템 1; 외부 배열 scalar 타입 및 도달 불가 분기 진단).
  개별 lane 기록보다 통합 환경의 경고 수를 우선한다. 전역 게임 gate,
  Godot 실행, FPS 측정은 이번 오프라인 자산 범위에서 실행하지 않았다.
- 아이템 마지막 결과는 첫 라운드보다 전반적으로 개선되었다고 주장할 수 없다.

- 전체 장면 네 패널의 단일 PNG는 1.5MB를 넘어서 전체 장면 보충판으로 분리했다.
  요구 크기를 줄이거나 양자화하지 않았다.
