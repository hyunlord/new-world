# ART-POLISH 결정 기록

## D1 — 초상·동물 스타일 계측은 보고 전용

목표 문서가 선언한 계측 변경을 그대로 적용한다. 초상과 동물은 judge v2
수치 및 이미지 모델 스타일 점수표를 남기되 합격 여부를 결정하는 게이트로
사용하지 않는다. 구조, 각각의 블라인드 시험, 오너 보드 등재를 별도로
판정한다. 이 조건 충족도 오너의 채택을 뜻하지 않는다. 아이템은 보정된
items family의 judge v2 스타일 게이트를 유지한다.

근거는 ENV1의 `docs/v8/artenv1/portrait_negative_controls.json`,
`portrait_calibration.json`, `animal_style_evidence.json`,
`animal_negative_model_review.json`이다. 초상 사진 대조군을 모델이
4/4/4/4로 평가했고, 초상·동물 수치 계측도 부정 대조군을 통과시켰다.
동물의 추가 이미지 모델 대조군은 사진·회화풍을 거절했으므로, 동물의
수치 계측 실패와 모델 점수표 결과를 같은 실패로 뭉뚱그리지 않는다.
기존 ENV1 판정이나 임계값은 수정하지 않는다.

## D4 — 초상 대상과 동물 방향

초상 재생성은 기존 결함 대상의 합집합인 9명만, 각 최대 2회다. 다른 25명은

## D5 — 재사용 목록의 기존 실패를 보존

명시된 13종 재생성 목록 밖의 9개 이미지를 유지한다. 이 9개 전부가
기존의 모든 기준을 통과한 것은 아니다. 창 `spear`는 ENV1 수치 스타일
`REJECTED_NUMERIC_RETRY_LIMIT`이고, `berry_basket`은 정확 종류 판독에서
한 리뷰어가 그릇으로 읽었다. 새 생성 목록을 임의로 넓히거나 재사용이라는
이유로 이 실패를 PASS로 바꾸지 않는다. 새 블라인드 시험은 22개 전체에
실시하며, 최종 스타일 경로표에도 창의 실패를 남긴다.

## D6 — 아이템 시험 실패 후의 한 번의 수정 라운드

최초 13종 외에는 생성하지 않았으며 라운드 0에서 유지된 작은 통나무,
돌도끼, 베리 바구니도 실제로 오독되었다. 목표의 후속 규칙
“Miss → one regeneration round on the misread kinds, two new reviewers”를
22개 시험 전체에 적용하여 이 3종도 수정 라운드에 포함한다. 이는 초기
재생성 대상을 사후 확대했다는 주장과 구별되며, 최초 선택본과 실패는
동결된 라운드 0에 보존한다. 수치만 실패한 중간·큰 통나무도 같은 라운드에
교정하여 총 16종을 한 번씩 생성한다. 각 ID의 전체 POLISH 시도는 3회 이하다.
기존 창은 판독 오답이 아니므로 재생성하지 않고 스타일 및 길이 조건 실패를
남긴다. 최종 시도 선택 규칙은 호출 전에 기록한다.

블라인드 ID 오타 3건은 원래 판독자가 같은 그림의 인쇄된 ID를 다시 확인하여
ID만 정정했다. 원시 답변 파일·이름·확신·설명은 수정하지 않았고 정정 파일을
별도 보존했다. 정답이나 점수는 판독자에게 공개하지 않았다.

## D7 — 마지막 아이템 판독의 의미 채점과 종료

마지막 라운드는 32px 답변을 먼저 파일로 고정한 뒤 64px를 열었다.
인쇄 ID 전사 오타가 다시 3건 있었고, 원래 판독자가 ID만 별도 정정했다.
첫 이름·설명·확신 및 32px 원본 응답은 그대로다.

독립 검토에서 bare `basket`를 BerryBasket으로 보는 임시 해석을 거절했다.
ENV1의 바구니/그릇 구분은 두 답변 모두 berries를 명시한 경우였으며,
설명란의 내용으로 첫 이름을 보완할 수 없다. 최종 점수는 A 9/22·11/22,
B 9/22·12/22(32px·64px)이며 모든 필수 쌍의 양쪽 리뷰어 충족 기준은 실패다.
임시 해석의 계산 결과도 외부 원시 기록으로 남겼다. 허용된 한 번의 수정
라운드가 끝났으므로 실패를 보존하고 생성·판독을 추가하지 않는다.
