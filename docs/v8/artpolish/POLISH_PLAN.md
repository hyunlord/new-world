# ART-POLISH 실행·검증 계획

승인된 계약: [POLISH_GOAL.md](POLISH_GOAL.md). 작업 모드: 직접 실행과
범위가 겹치지 않는 native subagents. 목표 문서의 수치·시도 상한 유지.

1. 목표·D1/D2와 예산을 기록하고 `v8/art-polish`에서 커밋한다.
2. 벽 합성기: 행동 테스트를 먼저 실패시키고 파라미터·굴 경계를 구현한다.
   기존 compositor 전체 테스트, 같은 crop의 legacy/dark 1×·2×,
   세 밝기 strip, 근접 보드를 실제 생성한다.
3. 동물: TEMPLATE_A1에 따라 늑대·사슴 시트를 생성·분리·정규화하고
   구조 및 보고용 스타일 평가를 수행한다. 두 새 판독자의 no-key 20프레임
   각 1×/2× 종·자세 시험을 채점한다. 실패 시 상한 내 한 번 재생성 라운드.
4. 초상: 지정된 9명만 재생성하고 34명 구조를 확인한다. 같은 연령·성별의
   서로 다른 옷/머리 distractor 3개를 고정 규칙으로 골라 두 새 판독자가
   34문항 4지선다 동일인 시험을 한다. 각각 30/34 기준 유지.
5. 아이템: 실루엣 설계표를 먼저 쓴다. 13종 재생성, 9종 유지. 고정 item
   judge v2 게이트와 두 새 판독자의 32px/64px 첫 이름 시험. 각 17/22,
   20/22 및 필수 혼동 쌍 조건을 독립 채점한다. 실패 시 상한 내 한 라운드.
6. 보드 5종과 밝기 strip을 실제 열어 확인하고 파일 크기·해시·원본
   추적·누락·예산·범위·정답 비노출·실패 보존을 감사한다.
7. 한국어 보고서에 라운드별 결과, 한계, M-ART2 경로표·파라미터,
   오너 선택 사항을 적는다. 승인을 주장하지 않는다.
8. 명시적 경로만 stage, Lore 커밋, `git push origin v8/art-polish`,
   `git ls-remote origin v8/art-polish`와 로컬 HEAD 일치를 확인한다.

게임 실행·게임 전체 gate는 이 아트 전용 변경의 증거를 대신하지 않는다.
검증은 compositor 테스트, 재현 가능한 asset 구조/해시 검사, 실제 이미지
검토, 독립 블라인드 원시 답변 및 채점으로 구성한다. 실패한 미술 기준은
재시도 한도가 끝나면 실패로 남기고 오너 판단 대기 보고서를 완성한다.
