# ART-PROD2 결정 기록

- D1: planner가 명시한 대로 sex는 성인만, age는 전체 12명을 채점한다. `(성인 sex 정답 + 전체 age 정답)/(성인 수 + 12) >= 0.83`. 40px 어린이의 성별은 읽을 수 있는 속성으로 요구하지 않는다는 목표의 근거를 따른다. 기존 PROD1 점수는 변경하지 않는다.
- D2: 사용자 목표의 브랜치·범위가 일반 프로젝트 규칙보다 우선한다. `v8/art-prod1`에서 `art/**`, `docs/v8/artprod2/**`만 변경한다. 게임 코드·merge·전역 문서 수정은 없다. 기존 `.gitignore`, `.ignore`, `.omo/`, `docs/art/`는 보존한다.
- D3: 원본 96회는 PROD1 역사로 보존하고 별도 외부 디렉터리에서 재절단한다. 재절단은 새 생성 횟수에 포함하지 않는다. 모든 시도를 평가하고 최초 완전 통과를 선택하며, 미통과 룩은 통과 프레임 수 최대/동률 최초 시도를 보고한다.
- D4: sleep은 alpha>=128 인체 bbox의 긴 축을 56/40px에 맞추고 실제 RGBA는 전체 보존한다. 기존 머리-왼쪽 회전·alpha0 trim·Lanczos·footline 규칙을 유지한다. 서 있는 네 자세는 S idle 공통 배율을 유지한다. 수면 별도 배율은 방향별 원본에 따라 다를 수 있어 두 방향 값을 각각 기록한다.
- D5: 추가 생성은 룩별 최대2회, 총40회이며 리뷰 교정도 포함한다. 첫 리뷰 실패 시 대상 룩에 한 번의 교정만 허용하고 새 리뷰어2명으로 재검사한다. 세 번째 리뷰 라운드는 없다.
- D6: Godot P1은 독립 art/proto 랩의 실제 windowed 렌더를 측정한다. 게임 시뮬레이션/bridge 성능을 의미하지 않는다. Chromium 캡처는 가독성 재생 증거로만 사용한다.
- D7: 4a127660의 Tested trailer는 비교 명령 실행을 기록했지만 `cmp` 결과를 잘못 성공으로 해석했다. 실제 차이는 목표 파일 끝의 개행 1개뿐이며 본문은 동일하다. 이 비교 실패를 숨기거나 커밋을 amend하지 않고 본 기록으로 정정한다. 목표 본문은 유지한다.

- D8: 전수 재절단 결과22/36(성인11, 어린이11)이다. 이전 수락 adult_F_loincloth_long_tied와 adult_M_hide_wrap_long_tied가 새 규칙에서 실패해 외부에 바이트 검증 보존 후 route_i에서 철회했다. 과거 수락 수로 새 규칙 통과를 대체하지 않는다. 잔여14룩만 추가 생성한다.
- D9: 인증 표본은 이미지/정답을 본 뒤 고르지 않는다. 가능하면 성인여5+성인남5+어린이여1+어린이남1을 의상·머리 층화 순서로 고른다. 불가능할 때만 목표의 최소 조건으로 fallback한다. 리뷰 교정 후에는 최초 표본 ID·속성·활동을 고정한다.
- D10: 재현성은96시트 두 독립 처리의 모든 파일 집합과 PNG 원시 바이트를 비교했다. JSON에는 실행 디렉터리 절대 경로만 정규화했다. 이 구분을 D1 보고에 그대로 공개한다.
