## 제 순위

1. **I-1**: 56px에서 머리·가죽·팔 구분이 가장 안정적이고, 선택 원본 중 유일하게 수치 통과했다.
2. **I-4**: 얼굴과 땋은 머리가 개성을 주지만 1×에서는 머리 디테일이 많이 사라진다.
3. **I-3**: 상투와 맨몸/허리천 구분은 쉽지만 근육 묘사와 높은 시점이 남아 있다.
4. **I-2**: 망토는 분명하나 작은 머리와 많은 털 디테일 때문에 1×에서 덜 선명하다.
5. **B**: 온전한 인간 모델이지만 작은 머리·가는 다리·두꺼운 윤곽이 05 인물 방향과 멀다.

이 순위는 직접 본 비교판의 판단이며 블라인드 가독성 시험이나 오너 승인을 대신하지 않는다.

## B 출처

공식 Quaternius Universal Base Characters Standard, CC0 1.0. 무료 팩에는 Superhero 남녀 2종과 머리 메시가 있고 의복 메시가 없다. 남성 + 짧은 Hair_Buzzed를 기존 TRIAL3b `render_b.py`의 frozen look 3으로 단일 still 렌더했다. Blender 4.5.14, 1024×1536 RGBA. URL·ZIP SHA-256·라이선스·재현 명령은 [ROUTE_B.md](ROUTE_B.md)에 있다. 마스크 수정·ID pass·클립은 수행하지 않았다.

## 검증과 한계

- 비교판과 군중판 실제 이미지를 열어 열/행, 크기, 비교 대상, 잘림을 확인했다. 보드 재현 스크립트와 소스 해시를 보존했다. Python의 Pillow 12.2.0에서 두 판을 byte-exact 재현했다. Pillow 13에서는 출력 바이트가 달라지므로 동일 결과 재현에는 12.2.0이 필요하다.
- 생성은 각 3회 상한으로 종료했다. 모든 원본은 `/Users/rexxa/work/arttrial5-data/generations/`에 있다. 1024×1536 원본은 보존하고, 저장소 파일은 1.5 MB 이하 작업본으로 만들었다. 크롭·균일 축소·합성 외 수정은 없다.
- 요청한 머리 약 30%, 단순화된 팔다리, 약 20° 시점은 완전히 달성되지 않았다. 특히 I-2는 더 사실적인 비율이다. 따라서 요구한 룩의 완전 충족이나 생산 표준 확정이라고 보고하지 않는다.
- 투명 RGBA를 생성했다. 도구의 검은 배경 미리보기에서는 갈색 후광처럼 보였으나 초원 합성에서는 두드러지지 않았다. 알파 후처리를 하지 않았으며 미세한 반투명 외곽은 원본 그대로 남아 있다.
- B는 의복 없는 베이스다. 원본 glTF의 누락 normal-map 경고와 frozen shader의 원본 속옷 텍스처 제거도 기록했다.
- 중간 모델 용량 오류로 실행이 중단됐다가 재개됐다. Part 0의 2시간 목표 달성을 주장하지 않는다. 실제 모델 추론 시간과 대기 시간을 분리 측정하지 않았다.
- Ruff, Python 구문 확인, `git diff --check`, 문서 검사 통과. 게임 빌드/전체 gate, 애니메이션, checker, FPS, Part 2 리뷰는 이번 범위가 아니며 검증하지 않았다.
- 변경은 `art/character/candidates/*`, 보드 PNG 2개와 provenance, `art/pipeline5/*`, `docs/v8/arttrial5/*`다. 기존 게임 코드나 스타일 기준은 변경하지 않았다. 단순화는 기존 렌더/판정/합성 함수 재사용이며 기존 코드 삭제는 없다.
