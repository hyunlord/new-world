- 최초 여름 원본은 팔레트보다 노란 색조였다. 원본과 실패 수치를 보존하고 자동 Lab 군집 수관 마스크에만 색차를 적용했다. `SUMMER_TRANSFORMS.json`은 전후 해시, 파라미터, 마스크 밖/알파 바이트 불변을 기록한다.
- 가는 겨울 가지는 축소 후 alpha≥128 연결성 검사를 실패했다. 픽셀 삭제 대신 대상별 최대 3회 안에서 굵고 성긴 가지로 재생성했다. 핵심 19장 최종 검사는 모두 통과한다. 생성 겨울 형태는 여름 v1과 같은 변환을 쓰지만 작은 나무의 줄기·뿌리 윤곽이 정확히 일치하지 않는다. `BARE_CHECKS.json` 수치를 보존하고 오너 판정 대상으로 남긴다.
- 기존 관목은 위에서 수직으로 본 소스였으므로 앞 3/4로 재생성했다. full은 열매 있음, bare/depleted는 열매 없음이며 잎이 없는 겨울 나무와 다른 의미다. 종 `berry`의 두 상태로만 사용한다.
