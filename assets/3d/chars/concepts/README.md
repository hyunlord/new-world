# M3D-2a concept inputs

Generated with the built-in Codex image generator on 2026-11-14. Each subject
has one reconstruction input (`SUBJECT.png`) and one reference turnaround
(`SUBJECT_turnaround.png`). One generation attempt per image; no paid external
3D service, Hunyuan3D or AniGen was used.

Shared prompt: stylized hand-painted Neolithic settlement game asset, earthy
ochre/tan/brown/olive palette, clear simple volumes, full body centred with
margin, three-quarter view, uniform light-grey background, even diffuse light,
no cast shadow, no props or text. Humans use a relaxed A-pose and bare feet.

Subject prompts:

- man: adult, short dark hair, ochre sleeveless plant-fibre tunic, brown cord belt.
- woman: adult, tied dark hair, olive/tan knee-length plant-fibre tunic, cord belt.
- child: about eight, short brown hair, fully clothed tan knee-length tunic.
- goat: tan/cream/brown coat, backward horns, beard, separated cloven hooves.
- aurochs: powerful shoulders, dark brown coat, pale muzzle, dorsal stripe,
  long pale horns and separated cloven hooves.

Turnaround prompt: retain the input's identity, proportions, clothes/markings
and palette; three equally scaled full-body FRONT/SIDE/BACK orthographic views.
These are reference-only: the goat's side is slightly three-quarter, and the
aurochs reference has a baseline. Do not pass turnaround sheets to TRELLIS.

Concept acceptance does not establish mesh, rig or game-size quality. Raw
generated meshes and execution evidence live in the external `m3d2-art` folder.
