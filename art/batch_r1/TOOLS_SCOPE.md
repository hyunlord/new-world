# Supplemental held tools and loads

They are separate from the84-wardrobe matrix. Each has the same ten frame names,
canvases and anchors, but work_a/carry show the declared tool/load. For these
activity alternatives alone, grinding/spinning/hoe work must look like its
actual action rather than copying the generic overhead axe gesture. Idle is
compared against the same matching shipped hide_wrap_short reference using
all five frozen strict metrics. All ten structural/visual gates still apply.
