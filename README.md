# WorldSim

석기시대의 작은 무리를 이끌어, 사람 하나하나의 손기술과 관계가 쌓여 마을이 되고, 기술이 사람 사이로 퍼지면서 시대가 저절로 넘어가는 **드워프 포트리스식 정착지 시뮬레이션**이다.

- 10명 안팎으로 시작해 출생과 이주로 30~200명까지 자란다. 구조는 수천 명까지 늘릴 수 있게 만든다.
- 플레이어는 파기·베기·짓기·구역·작업 우선순위·제작 주문을 내리고, 사람들은 숙련과 기질에 따라 스스로 일을 고른다. 위협이 오면 림월드식으로 사람을 소집할 수 있다.
- 기술은 사람이 가지고, 사람 사이로 퍼지고, 마지막 전승자가 죽으면 사라진다. 시대는 표지 기술이 얼마나 퍼졌는지로 관측된다.
- 시간: 1배속에서 하루가 2분(1,440틱 ÷ 초당 12틱, M1부터)이고 1~4 키가 1~4배속(초당 12~48틱), 스페이스가 일시정지다(M2부터; P는 작업 우선순위 표). 달력은 계절 6일·1년 24일이고 나이는 해로 센다(M1.5). 화면은 어두운 흙빛 정면 탑다운, 사람 하나가 타일 한 칸이다.

자세한 방향은 [docs/VISION.md](docs/VISION.md), 진행 상황은 [docs/ROADMAP.md](docs/ROADMAP.md).

## 빌드와 실행

평소에는 다음 한 줄로 원격 `v8/main`의 게임을 연다. 실행기는 버전별 플레이 작업 트리를 준비하고 필요한 빌드·가져오기(import)를 한 뒤 1920×1080 창을 연다.

```bash
/Users/rexxa/work/new-world-play2-dev/tools/play.sh main
```

실행기는 별도 `new-world-play2-dev` 체크아웃에 두고, 게임은 `/Users/rexxa/work/new-world-play/main` 하위 작업 트리에서 연다. 실행기 체크아웃은 지우지 않는다. `/Users/rexxa/work/new-world-play` 자체에 `git worktree add`를 하지 않는다. `--update-only`로 게임 작업 트리를 미리 준비할 수 있다. V8-PLAY2의 실제 전달·검증 상태와 오너 명령은 [보고서](docs/v8/play2/PLAY2_REPORT.md)에 기록한다.

필요한 것은 Godot 4.6, Rust의 `cargo`, Git과 Apple 명령줄 도구다. Godot은 `GODOT_BIN` → 저장소의 `tools/v8/godot_bin.sh` 경로 → Spotlight → `/Applications/Godot.app` 순서로 찾는다. 이 맥의 기본 경로는 `/Users/rexxa/Downloads/Godot.app/Contents/MacOS/Godot`다. 첫 빌드에는 Rust 도구·패키지를 받는 인터넷 연결이 필요할 수 있다. Godot이 처음 실행될 때 macOS의 열기 확인은 직접 승인한다.

### 더블클릭으로 실행

바탕화면 바로가기를 처음 만들거나 예전 개발 작업 트리 경로에서 바꿀 때만 오너가 다음 한 줄을 실행한다. V8-PLAY2 작업은 바탕화면을 변경하지 않는다.

```bash
ln -sf /Users/rexxa/work/new-world-play2-dev/tools/play/WorldSim.command ~/Desktop/WorldSim.command
```

이후 `WorldSim.command`를 더블클릭한다. 터미널에 준비 단계와 로그 경로가 나오고 게임 창이 열린다. 최초 실행은 빌드·에셋 가져오기 때문에 시간이 걸리며, 이후에는 Cargo가 증분 빌드로 최신 상태를 확인하고, 변경이 없으면 가져오기를 생략한다. 창을 닫으면 게임이 끝난다. 실패하면 터미널에 이유가 남는다. 과거 측정 시간을 현재 빌드의 실행 시간으로 보장하지 않는다.

### 처음 화면과 처음 할 일

새 게임은 **마을 스스로**가 켜져 시작한다. 비축·벌목·주거·제작·식량·기술 전승의 기본 명령을 자동으로 내리며 직접 내린 명령이 우선한다. 오른쪽 위에서 전부·집만·먹을 것만·끔을 고른다. 이주민 수락과 징집은 직접 결정한다. 오른쪽 경고를 누르면 원인으로 이동하고, 왼쪽 아래 학습 카드가 조작을 안내한다. 오른쪽 아래 미니맵·속도·확대 버튼을 사용하거나 두 손가락 스크롤과 핀치로 지도를 움직인다. 아래 순서는 수동 조작 방법이다.

M-ART2.1은 64px 타일, Route I 사람과 초상, 재료 그림을 조합해 코드로 그리는 벽, 초록 나무와 둥근 물가를 사용한다. **기본 확대는 1×**이며 캠프를 중심으로 시작한다. 휠이나 `-`·`=`로 ¼×·½×·1×·2×를 고르면 확대 표시가 바뀐다. 1× 미만에서는 사람·동물이 마커가 되고, ¼×의 숲은 수관 덩어리로 보인다. 사람을 클릭하면 초상과 현재 상태를 확인할 수 있다. 방·기술 전승·늑대·이주민·교역도 현재 게임에 포함되어 있다.

1. **Space**로 시간을 멈추고 **H**로 캠프를 찾는다. 사람을 클릭해 상태를 보고 Esc로 상세 창을 닫는다. P는 일시정지가 아니라 작업 우선순위다.
2. **F2**를 누르고 가까운 빈 땅을 드래그해 비축 구역을 만든다. 오른쪽 클릭이나 Esc로 명령 모드를 끝낸다.
3. **F1**로 숲 일부를 드래그해 벌목을 지정하고 Space로 재개한다. 사람들이 나무를 베고 통나무를 비축 구역으로 나르는지 본다.
4. **F3 → 5**로 통나무 벽을 선으로 배치하되 출입구 한 칸을 남긴다. **F3 → 6**으로 문, **→ 7**로 바닥, **→ 8**로 침상을 놓는다. 벽·바닥은 드래그로 선, Shift+드래그로 사각형이다. 벽 사각형은 완전히 닫히므로 문 자리는 청사진 단계에서 F6으로 취소해 비워 둔다.
5. **R**로 방 보기를 켜고 완성된 방 안을 클릭한다. 지붕·문·침상과 침실 역할을 확인한다. 별도의 방은 역할을 **창고**로 정하고 안에 F2 비축 구역을 둔다.
6. **P**에서 사람별 작업 우선순위를 조정한다. F3으로 만든 돌깎이 자리·목공대 같은 작업장을 클릭해 제작 주문을 넣고 필요한 재료가 있는지 확인한다.
7. **K**에서 기술·스승·제자를 고르고 가르치기 명령을 내린다. 명령이 거절되면 토스트의 이유를 확인한다.
8. **T**로 기술 지도를 열어 보유자와 사라질 위험이 있는 기술을 확인한다. 기술을 선택한 뒤 K를 누르면 그 기술의 가르치기 창을 연다.
9. 늑대가 접근하면 사람을 클릭하고 **D**로 징집한다. 명령 모드를 끝낸 뒤 오른쪽 클릭으로 이동하거나 동물을 공격한다. 다시 D를 눌러 일상 작업으로 돌려보낸다.
10. **N**으로 이웃을 확인한다. 이주민 배너·인물에서 수락/거절을 선택하고, 교역 무리·배너를 클릭해 물건과 수량을 골라 거래한다. 이주민 도착 대화창은 1배속일 때 자동으로 시간을 멈춘다. **F5**로 저장하고 **F9**로 불러온다.

### 실행기 옵션과 문제 확인

```text
usage: tools/play.sh [version] [--seed N] [--speed 1-4] [--no-build] [--headless-check] [--update-only] [-- Godot 인자…]
version: main (기본), wip, m1, v8-0, v7, 커밋/태그/브랜치
```

- `--update-only`: 작업 트리를 업데이트하고 빌드·가져오기까지 준비한 뒤 창 없이 종료한다.
- `--headless-check`: 준비 후 창 없이 300프레임 확인한다. 실제 화면·입력 검증을 대신하지 않는다.
- `--no-build`: 라이브러리가 있을 때만 빌드를 생략한다. 오래된 라이브러리는 최신 코드 검증이 아니다.
- `--seed`, `--speed`: 해당 버전이 인자를 읽을 때만 전달하며 미지원이면 경고한다. 속도는 게임 안의 1–4로 바꿀 수 있다.
- `-- --print-fps`처럼 `--` 뒤 인자는 Godot에 전달한다.
- 오프라인에서 fetch가 실패하면 경고와 함께 마지막으로 받은 원격 상태를 사용한다. 아직 받지 않은 버전이나 Rust 의존성까지 오프라인에서 준비할 수 있다는 뜻은 아니다.
- 로그는 `/Users/rexxa/work/play-data/logs/<버전>-<시각>-<PID>.log`에 남는다. 실패 시 출력된 로그 경로와 종료 코드를 확인한다: 1 빌드·가져오기·작업 트리·실행 오류, 2 Godot 없음, 3 모르는 버전, 4 인자 오류.
- 버전별 공간은 별도다. 조사 시작 시 이 맥은 `m1` 1.4G, `main` 3.5G, `v7` 4.3G였으며 빌드·에셋에 따라 달라진다. 옛 버전 실행과 안전한 정리는 [PLAY.md](docs/v8/play2/PLAY.md)를 따른다. 플레이 작업 트리는 원래 클론의 Git 관리 디렉터리에 연결되어 있으므로 원래 클론을 옮기거나 지우지 않는다.

**English.** WorldSim is a Dwarf Fortress–style stone-age settlement sim: about ten founders grow into a village of 30–200 people; the player gives orders (dig, chop, build, zones, work priorities, craft orders) and people choose their own work; technology is owned by individuals, spreads between them and is lost when its last bearer dies, and eras are observed from how widely marker technologies have spread. The simulation is Rust (hecs ECS, deterministic, integer math) behind a Godot 4.6 GDExtension bridge; GDScript only draws and reads. Build the bridge with `cd rust && cargo build -p sim-bridge`, import with `Godot --headless --path . --import --editor --quit` (twice on a fresh checkout; judge the second run), run with `Godot --path .`, and check a change with `bash tools/v8/gate.sh <log_dir>`. Agents start at [AGENTS.md](AGENTS.md); the structure is in [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md).
